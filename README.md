## Models and LLM tooling

- Mercor raised a $750m Series D at a $20B valuation, reporting $3B annualized run rate, with 5 million experts on its network <sup>[1](<https://latent.space/p/ainews-mercor-750m-series-d-at-20b-valuation-3b-run-rate/>)</sup>. The company says it spends 3x as much on inference as on employee salaries <sup>[1](<https://latent.space/p/ainews-mercor-750m-series-d-at-20b-valuation-3b-run-rate/>)</sup>.
- BotPsy, a sub-billion-parameter agentic language model aimed at on-device personal assistant use, is presented with benchmark results on tool use, knowledge, instruction following and multi-turn conversations <sup>[2](<https://huggingface.co/blog/qvac/botpsy>)</sup>. Its authors argue small specialized agents can match frontier models on specific tasks at much lower cost and with better privacy <sup>[2](<https://huggingface.co/blog/qvac/botpsy>)</sup>. Multi-step information retrieval is reported as its weak spot <sup>[2](<https://huggingface.co/blog/qvac/botpsy>)</sup>.

## Coding agents and developer tools

- At the AI Engineer Code Summit, OpenAI ran a workshop on new ways of working with Codex, covering cloud execution, personal agents between sessions and voice steering of coding tasks <sup>[3](<https://latent.space/p/codex-work/>)</sup>. The write-up notes the shift to cloud is still confusing for many users of Codex, Claude and Antigravity <sup>[3](<https://latent.space/p/codex-work/>)</sup>.
- GitHub now lets enterprise GitHub Apps call the enterprise-level Copilot seat management APIs, using a new fine-grained permission <sup>[4](<https://github.blog/changelog/2026-11-10-github-app-support-for-enterprise-copilot-seat-management>)</sup>.
