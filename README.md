## AI and ML

- OpenAI and Poland's NASK are partnering on AI safety, security and technical research to strengthen safeguards <sup>[1](<https://openai.com/index/openai-nask-ai-safety-security-partnership>)</sup>.
- Three OpenAI safety researchers were fired after security officers found Signal chats with disappearing messages enabled on their personal devices; OpenAI says the firings were for violating policies on sensitive information, not for raising safety concerns, while the researchers argue the move will close a channel for independent third-party insight <sup>[2](<https://www.wsj.com/tech/ai/the-signal-chats-that-cost-openai-researchers-their-jobs-594c5853>)</sup>.
- Microsoft published a post on turning database grading into RL rewards to post-train agents with ThinkingBox <sup>[3](<https://huggingface.co/blog/microsoft/thinkingbox-training>)</sup>.
- PyTorch Conference North America 2026 (October 20–21, San Jose, 3,500+ attendees) focused on open-source training and serving of models across chips and clouds, covering PyTorch, vLLM, DeepSpeed, Ray, Helion and Safetensors <sup>[4](<https://pytorch.org/blog/pytorch-conference-north-america-2026-accelerating-open-intelligence-together/>)</sup>.

## Developer tools and software engineering

- GitHub Copilot in Visual Studio's September update adds a Git agent that can summarize a pull request with navigable links (requires the GitHub or Azure DevOps MCP server), and Bring Your Own Model is in preview <sup>[5](<https://github.blog/changelog/2026-10-22-github-copilot-in-visual-studio-september-update-2>)</sup>.
- Copilot usage metrics now show the names of custom skills, agents, MCP servers, slash commands and plugins instead of "other", with up to 25 entries per list <sup>[6](<https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api>)</sup>.
- Anthropic built its own source control system, Scion, reportedly because its coding output is closer to that of a company several times its size; Google and Meta also moved off Git to custom systems <sup>[7](<https://blog.pragmaticengineer.com/the-pulse-anthropic-builds-its-own-source-control-system/>)</sup>.
- Software slowness is attributed to bad design rather than slow languages, with the argument that most programs can't be meaningfully sped up by rewriting them in C or Rust <sup>[8](<https://www.seangoedecke.com/software-is-slow-because-of-bad-design-not-slow-languages/>)</sup>.

## Security and infrastructure

- Ondřej Surý, a PHP patch maintainer, describes how a handful of volunteers deliver most of PHP's distribution and fixes for recently revealed vulnerabilities amid an AI-cybersecurity crisis <sup>[9](<https://www.theatlantic.com/technology/2026/10/man-who-saved-internet-php-vulnerability/689123/?amp%3Butm_source=tldrnewsletter>)</sup>.
