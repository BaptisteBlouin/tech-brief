## AI models and open weights

- Meta released Muse Spark Open, an 816B-total, 42B-active MoE with open weights, which Artificial Analysis scores at 39 on its Intelligence Index, the highest for a US open-weights model <sup>[1](<https://www.latent.space/p/ainews-high-taste-testers-ep-1>)</sup>.

## Coding agents and code review

- The Claude Code team describes running review continuously during development rather than only at the end: most changes are reviewed and fixed by Claude at least once before a human is asked to look, which catches routine mistakes and frees reviewer attention for higher-level questions <sup>[2](<https://simonwillison.net/2026/Oct/16/code-review/>)</sup>.
- The same write-up reframes review around the question "what could go wrong with this change, and which check, automated or human, should catch it?" rather than "did a human read the code?" <sup>[2](<https://simonwillison.net/2026/Oct/16/code-review/>)</sup>.
