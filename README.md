## AI models

- Kimi K3.1 Pro, a post-trained version of Kimi K3 with substantially larger post-training compute, is reported as a 2.8T-parameter open-weights model that Latent Space says beats Fable 5.1 <sup>[1](<https://latent.space/p/ainews-kimi-31/>)</sup>. The release also comes with a Pro Highspeed API that the same newsletter says runs 2 to 3 times faster <sup>[1](<https://latent.space/p/ainews-kimi-31/>)</sup>.

## Developer tools and coding agents

- GitHub's Copilot usage metrics API now includes a new `totals_by_client` array in the enterprise, organization and per-user 1-day and 28-day reports <sup>[2](<https://github.blog/changelog/2026-10-23-usage-metrics-api-adds-usage-from-tools-like-opencode>)</sup>. Each entry gives request count, session count and token usage per client, so usage from tools such as OpenCode, Claude Code and Codex can be tracked <sup>[2](<https://github.blog/changelog/2026-10-23-usage-metrics-api-adds-usage-from-tools-like-opencode>)</sup>.
- Each client entry also breaks usage down by model, with a `model_selection_mode` field showing whether the model was chosen directly by the user or selected automatically <sup>[2](<https://github.blog/changelog/2026-10-23-usage-metrics-api-adds-usage-from-tools-like-opencode>)</sup>.
