## Security and infrastructure

- F5 and nginx.org disclosed ten nginx vulnerabilities on November 18, 2026 <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>. Five of them, named nginx2root by the Xint team, are memory corruption flaws that an unauthenticated attacker can use to crash an nginx worker or, per Xint's research, run commands on the server <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>.
- Xint also found a Linux kernel bug that can turn that foothold into root on the host, including from inside a Docker container <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>.
- Cloudflare states that origins reachable only through its proxy cannot be reached by attackers on the vulnerable code paths for the most serious flaws <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>.
