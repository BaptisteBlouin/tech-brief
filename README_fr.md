## IA et agents

- Le contournement de Simon Willison pour une récente erreur de dépendance de Python 3.15 : supprimer le fichier `uv.lock`, car un verrou épinglé sur une version sans wheel pour Python 3.15 peut casser la construction (par exemple `watchfiles==1.1.1` qui échoue face à la version maximale prise en charge par PyO3, Python 3.14) <sup>[1](<https://simonwillison.net/2026/Nov/1/delete-uv-lock-first/>)</sup>.
- MIT Technology Review soutient que le web agentique est arrivé : la vision du « web sémantique », vieille de plusieurs décennies, selon laquelle des agents logiciels autonomes agiraient pour le compte des utilisateurs, devient réalité <sup>[2](<https://www.technologyreview.com/2026/11/02/1147846/the-agentic-web-is-here/>)</sup>.

## Ingénierie des données

- Data Engineering Weekly #294 décrit un changement dans la conception des systèmes : on passe d'approches basées sur les workflows à des approches basées sur l'intention, avec de nouveaux défis en matière d'infrastructure, de gestion des identités, d'observabilité, de sécurité et d'isolation <sup>[3](<https://www.dataengineeringweekly.com/p/data-engineering-weekly-294>)</sup>.
- La même lettre d'information note que les exercices de programmation traditionnels et les bootcamps pourraient compter moins pour les nouveaux ingénieurs de données, à mesure que le codage à l'ancienne disparaît <sup>[3](<https://www.dataengineeringweekly.com/p/data-engineering-weekly-294>)</sup>.
