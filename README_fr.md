## Outils d'IA

- Le plugin datasette-llm 0.1a11 de Datasette prend désormais en charge les points d'accès compatibles OpenAI, ce qui permet à Datasette d'utiliser tout modèle servi derrière ce protocole <sup>[1](<https://simonwillison.net/2026/Nov/14/datasette-llm/>)</sup>.
- Des exécuteurs de modèles locaux comme LM Studio, Ollama et llama.cpp peuvent être branchés de cette manière ; llama.cpp vient tout juste d'atteindre la version 1.0.0 <sup>[1](<https://simonwillison.net/2026/Nov/14/datasette-llm/>)</sup>.
- Une configuration concrète est donnée : lancer Datasette via uvx avec un modèle Qwen local, accessible sur une base d'API localhost, permet d'obtenir une instance locale de Datasette Agent <sup>[1](<https://simonwillison.net/2026/Nov/14/datasette-llm/>)</sup>.
