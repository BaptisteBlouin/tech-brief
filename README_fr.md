## Sécurité et infrastructure

- F5 et nginx.org ont divulgué dix vulnérabilités de nginx le 18 novembre 2026 <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>. Cinq d'entre elles, baptisées nginx2root par l'équipe Xint, sont des failles de corruption de mémoire qu'un attaquant non authentifié peut utiliser pour faire planter un worker nginx ou, selon les recherches de Xint, exécuter des commandes sur le serveur <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>.
- Xint a également découvert une faille du noyau Linux qui peut transformer cette prise de pied en accès root sur l'hôte, y compris depuis un conteneur Docker <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>.
- Cloudflare indique que les origines accessibles uniquement via son proxy ne peuvent pas être atteintes par des attaquants sur les chemins de code vulnérables pour les failles les plus graves <sup>[2](<https://blog.cloudflare.com/nginx2root/>)</sup>.

## Outils pour développeurs

- La page Overview des pull requests de GitHub, en préversion publique depuis le 5 novembre 2026, n'affiche plus les vérifications facultatives échouées comme bloquant la fusion des pull requests <sup>[3](<https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview>)</sup>.
- L'activité de force-push renvoie désormais vers les commits anciens et nouveaux pour comparaison, et l'activité des commits affiche des horodatages <sup>[3](<https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview>)</sup>.

## Agents IA et outillage

- Claire Vo, qui dirige ChatPRD, décrit un afflux de fraudes sur les tokens de la part de groupes qui exploitent l'essai gratuit du produit et les codes promo pour revendre des tokens ou exécuter des travaux commerciaux via son agent <sup>[4](<https://simonwillison.net/2026/Nov/20/token-fraud-is-here-and-its-bad/>)</sup>.
- Elle signale qu'une invite courante dans ces abus était la génération de SVG de pélicans à vélo, que l'auteur suggère pouvoir servir à identifier la famille de modèles sous-jacente <sup>[4](<https://simonwillison.net/2026/Nov/20/token-fraud-is-here-and-its-bad/>)</sup>.
- Les agents de Linear créaient 3 % de son travail il y a un an, et en créent aujourd'hui plus de la moitié <sup>[5](<https://latent.space/p/linear-scaling/>)</sup>. Linear a publié un serveur MCP, une plateforme permettant d'intégrer des agents à Linear, ainsi que des intégrations avec Codex, Cursor et GitHub Copilot <sup>[5](<https://latent.space/p/linear-scaling/>)</sup>.
