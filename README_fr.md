## Industrie et marché de l'IA
Anthropic vise un taux de fonctionnement annuel de $100B d'ici la fin de l'année, actuellement à $80B, tandis que les estimations de valorisation ont chuté jusqu'à $1T avec une probabilité en baisse de 18 % dans un contexte de correction du marché qui a fait reculer le Nasdaq d'environ 10 % <sup>[1](<https://latent.space/p/ainews-anthropic-ipo-whither-now/>)</sup>.

## Outils de développement et assistants de codage IA
Les paramètres de révision de code de GitHub Copilot sont désormais gérables via les API REST et GraphQL, depuis la politique d'entreprise jusqu'aux dépôts individuels, avec des champs d'attribution explicites pour identifier les révisions et commentaires de Copilot <sup>[2](<https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates>)</sup>. 
Le commentaire d'aperçu de la révision est plus compact, et la mise à jour inclut des correctifs pour la facturation, les révisions automatiques et la fiabilité dans les plans Copilot Pro, Pro+, Max, Business et Enterprise <sup>[2](<https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates>)</sup>. 
Les consommateurs d'API peuvent désormais voir l'effort de révision utilisé, ainsi que les compétences, les serveurs MCP et les instructions personnalisées que Copilot a signalés comme sources d'un commentaire <sup>[2](<https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates>)</sup>. 
Les administrateurs d'entreprise peuvent activer ou désactiver la révision de code pour toutes les organisations ou déléguer ce choix aux administrateurs d'organisation via l'API <sup>[2](<https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates>)</sup>.
