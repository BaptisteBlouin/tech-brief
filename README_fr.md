## Modèles et outils LLM

- Mercor a levé 750 M$ dans une Série D, à une valorisation de 20 Md$, avec un revenu annualisé de 3 Md$ déclaré et 5 millions d'experts dans son réseau <sup>[1](<https://latent.space/p/ainews-mercor-750m-series-d-at-20b-valuation-3b-run-rate/>)</sup>. L'entreprise affirme consacrer trois fois plus de budget à l'inférence qu'aux salaires de ses employés <sup>[1](<https://latent.space/p/ainews-mercor-750m-series-d-at-20b-valuation-3b-run-rate/>)</sup>.
- BotPsy, un modèle de langage agentique de moins d'un milliard de paramètres destiné à un usage d'assistant personnel sur appareil, est présenté avec des résultats de benchmarks portant sur l'usage d'outils, les connaissances, le suivi d'instructions et les conversations à plusieurs tours <sup>[2](<https://huggingface.co/blog/qvac/botpsy>)</sup>. Ses auteurs soutiennent que de petits agents spécialisés peuvent égaler les modèles de pointe sur des tâches précises, à un coût bien moindre et avec une meilleure confidentialité <sup>[2](<https://huggingface.co/blog/qvac/botpsy>)</sup>. La recherche d'information en plusieurs étapes y est signalée comme son point faible <sup>[2](<https://huggingface.co/blog/qvac/botpsy>)</sup>.

## Agents de programmation et outils pour développeurs

- Lors de l'AI Engineer Code Summit, OpenAI a animé un atelier sur de nouvelles façons de travailler avec Codex, couvrant l'exécution dans le cloud, les agents personnels entre les sessions et le pilotage vocal des tâches de code <sup>[3](<https://latent.space/p/codex-work/>)</sup>. Le compte rendu note que le passage au cloud reste déroutant pour de nombreux utilisateurs de Codex, Claude et Antigravity <sup>[3](<https://latent.space/p/codex-work/>)</sup>.
- GitHub permet désormais aux GitHub Apps d'entreprise d'appeler les API de gestion des sièges Copilot au niveau de l'entreprise, grâce à une nouvelle permission granulaire <sup>[4](<https://github.blog/changelog/2026-11-10-github-app-support-for-enterprise-copilot-seat-management>)</sup>.

## Industrie et adoption de l'IA

- OpenAI offre un an gratuit de ChatGPT Plus aux vétérans et aux militaires en reconversion, plus de 20 000 personnes en ayant déjà profité <sup>[5](<https://openai.com/index/chatgpt-plus-for-veterans>)</sup>.
