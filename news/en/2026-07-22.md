## Security and Governance
- **AI cybersecurity** emerges as a major theme: Sakana and Google release **cyber-specialized models** <sup>[34](<https://www.latent.space/p/ainews-ai-cybersecurity-becomes-top>)</sup>, while discussions focus on **runtime enforcement** (not just prompts) for agent governance <sup>[35](<https://www.docker.com/blog/runtime-enforcement-not-runtime-advice/>), [36](<https://www.docker.com/blog/agentic-ai-security-ciso-panel/>)</sup>.
- **ServiceNow AI Platform RCE flaw** is actively exploited; allows sandbox escape and remote code execution <sup>[37](<https://www.bleepingcomputer.com/news/security/critical-servicenow-code-execution-flaw-now-exploited-in-attacks/>)</sup>.
- **7-Zip RCE vulnerability** (heap-based buffer overflow in XZ processing) requires manual updates <sup>[38](<https://www.bleepingcomputer.com/news/security/update-now-7-zip-fixes-rce-flaw-exploitable-with-malicious-archives/>)</sup>.
- **North Korean "Contagious Interview" campaign** uses fake coding interviews to deliver trojanized repos with steganography-based payloads targeting developers <sup>[39](<https://www.elastic.co/security-labs/contagious-interview-malware-svg-steganography>)</sup>.
- **OAuth mix-up attacks** (CVE-2026-59208) exploit missing `iss` parameter validation in token exchange; defenders urged to enforce RFC 9207 client-side <sup>[40](<https://workos.com/blog/oauth-mix-up-attacks-rfc-9207>)</sup>.
- **Docker** highlights **agentic AI security risks**, advocating for runtime guardrails over prompt-based controls <sup>[35](<https://www.docker.com/blog/runtime-enforcement-not-runtime-advice/>), [36](<https://www.docker.com/blog/agentic-ai-security-ciso-panel/>), [41](<https://www.docker.com/blog/coding-agent-horror-stories-the-agent-that-deleted-production/>)</sup>.
