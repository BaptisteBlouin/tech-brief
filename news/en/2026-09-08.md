## Security and Reliability
- Offensive security capabilities are becoming **cheaper and more abundant**, making timely bug remediation and robust infrastructure critical; AI-assisted formalization helps but spec-to-code integration remains hard <sup>[27](<https://blog.zksecurity.xyz/posts/the-year-finding-bugs-became-cheap/>)</sup>.
- **PostGREShell (CVE-2026-6471)** affects PostgreSQL 9.4–18: a low-privilege REPLICATION account can load attacker code, gain superuser access, and persist; patch, restrict pg_hba.conf, remove unused replication privileges, block outbound SMB/NFS, and monitor replication slots <sup>[28](<https://www.cyera.com/pt-br/research/postgreshell-the-database-powering-much-of-the-internet-had-an-open-door-for-12-years>)</sup>.
- **N‑able patches max-severity CVE-2026-86218** in N-central amid ongoing attacks; unauthenticated code execution on internet-exposed servers; ~1,500 exposed instances; apply Hotfix 4 immediately <sup>[29](<https://www.bleepingcomputer.com/news/security/n-able-patches-max-severity-n-central-flaw-amid-ongoing-attacks/>)</sup>.
- **ConnectWise warns of a new unpatched file transfer flaw** in ScreenConnect (cloud and on-prem) <sup>[30](<https://www.bleepingcomputer.com/news/security/connectwise-warns-of-new-screenconnect-flaw-without-patch/>)</sup>.
- **JSCeal malware** bypasses Google authentication using stolen session cookies; distributed via fake TradingView installers; also harvests passwords, OAuth tokens, and manipulates traffic for Binance, Bybit, Ledger <sup>[31](<https://thehackernews.com/2026/09/jsceal-malware-can-bypass-google.html>)</sup>.
- **Liquid Network** lost ~$320 M in Bitcoin (≈4,000 BTC) via a bridge exploit; attackers claim they are “good guys” and will return most funds after fixes <sup>[32](<https://www.theregister.com/security/2026/09/07/hackers-drain-320m-in-bitcoin-from-liquid-network-claim-theyre-the-good-guys/5294770>)</sup>.
- **Manchester Airports Group** data on 8.8 M people leaked after refusing ransom <sup>[33](<https://www.securityweek.com/manchester-airports-group-data-on-8-8-million-people-leaked-after-ransom-refusal/>)</sup>.

- **Wiz Red Agent** found a GitHub Copilot-assisted regression in a Snowflake workflow that enabled template injection and access to Snowflake’s internal Jira <sup>[35](<https://www.wiz.io/blog/red-agent-snowflake-copilot-cicd-bug>)</sup>.
