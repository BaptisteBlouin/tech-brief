## AI and ML

- OpenAI and Poland's NASK are partnering on AI safety, security and technical research to strengthen safeguards <sup>[1](<https://openai.com/index/openai-nask-ai-safety-security-partnership>)</sup>.
- Three OpenAI safety researchers were fired after security officers found Signal chats with disappearing messages enabled on their personal devices; OpenAI says the firings were for violating policies on sensitive information, not for raising safety concerns, while the researchers argue the move will close a channel for independent third-party insight <sup>[2](<https://www.wsj.com/tech/ai/the-signal-chats-that-cost-openai-researchers-their-jobs-594c5853>)</sup>.
- OpenAI is reportedly closing a funding round of up to $30 billion at a $1.25 trillion valuation, led by UAE investors and positioned as a bridge ahead of a potential IPO <sup>[3](<https://www.cnbc.com/2026/10/22/openai-funding-round-uae-investors.html>)</sup>.
- An internal OpenAI model found a counterexample to Erdős's unit distance conjecture, and OpenAI later published a proof of the Cycle Double Cover problem and solutions to ten more open problems; Anthropic published a formalization of Fermat's Last Theorem <sup>[4](<https://latent.space/p/ai-is-getting-good-at-math/>)</sup>.
- Kimi K3.1 Pro is available on the Moonshot API at $2.00 per million input tokens and $10 per million output tokens, with full open weights promised by November 4, 2026; Artificial Analysis scored it 55, behind only Claude Opus 5.5 (58) <sup>[5](<https://simonwillison.net/2026/Oct/23/kimi-k31-pro/>)</sup>.
- Claude Duet is a research-preview agent that runs on a cloud computer and keeps working after the app is closed; Anthropic adds a classifier that checks drafted messages before they go out and says the agent never sees passwords, cookies or tokens <sup>[6](<https://claude.com/resources/articles/claude-duet-safety-privacy-and-security>)</sup>.
- Claude Cowork and chat are now unified and generally available for Claude Enterprise, with agentic work running in an Anthropic-managed cloud environment and a new Efficient mode for usage <sup>[7](<https://claude.com/resources/articles/unified-claude-enterprise>)</sup>.
- Anthropic's latest Claude models embed a SynthID-Text-based watermark in text output to comply with the EU AI Act, nudging choices among near-equivalent words without adding hidden characters <sup>[8](<https://www.oreilly.com/radar/the-latest-anthropic-claude-models-contain-ai-text-watermarks-what-does-this-mean-for-you>)</sup>.
- JOLT is Perplexity's self-distillation method that trains a model as both teacher and student, improving performance and training efficiency on math, coding and agentic tasks <sup>[9](<https://www.perplexity.ai/hub/blog/a-good-teacher-meets-the-student-where-they-are>)</sup>.
- Microsoft-Decision-1, a 9B Qwen-based model, scores predefined answer options with confidence probabilities rather than generating text <sup>[10](<https://shattered.io/microsoft-decision-1-qwen3-5-9b-model-2026/>)</sup>.
- Cisco's Antares-1B, post-trained from IBM Granite 4.0 1B, locates vulnerable files offline using up to 15 read-only sandboxed shell commands, reaching fourth place in file F1 on Cisco's 500-repo benchmark <sup>[11](<https://blogs.cisco.com/cisco-devnet/antares-security-analyst-laptop-part-1>)</sup>.
- Stream's incident agent gathers logs, metrics and code references, has a fresh session challenge its conclusions, and keeps engineers approving every fix, with 22 evaluation cases built from real incidents <sup>[12](<https://getstream.io/blog/ai-agent-production-investigation/>)</sup>.

## Developer tools and software engineering

- GitHub Copilot in Visual Studio's September update adds a Git agent that can summarize a pull request with navigable links (requires the GitHub or Azure DevOps MCP server), and Bring Your Own Model is in preview <sup>[13](<https://github.blog/changelog/2026-10-22-github-copilot-in-visual-studio-september-update-2>)</sup>.
- Copilot usage metrics now show the names of custom skills, agents, MCP servers, slash commands and plugins instead of "other", with up to 25 entries per list <sup>[14](<https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api>)</sup>.
- Anthropic built its own source control system, Scion, reportedly because its coding output is closer to that of a company several times its size; Google and Meta also moved off Git to custom systems <sup>[15](<https://blog.pragmaticengineer.com/the-pulse-anthropic-builds-its-own-source-control-system/>)</sup>.
- Software slowness is attributed to bad design rather than slow languages, with the argument that most programs can't be meaningfully sped up by rewriting them in C or Rust <sup>[16](<https://www.seangoedecke.com/software-is-slow-because-of-bad-design-not-slow-languages/>)</sup>.
- GitHub Actions workflow lockfiles are in public preview, pinning actions and their transitive dependencies to reviewed commits, with a CLI extension, Dependabot integration and policies requiring their use <sup>[17](<https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview/>)</sup>.
- AI21 cut GitLab Duo Code Review's estimated token cost per pull request from $0.589 to $0.0135 on a public benchmark, combining a switch to DeepSeek V4 Flash with context compaction, while F1 rose from 46.4% to 47.2% <sup>[18](<https://www.ai21.com/blog/gitlab-case-study/>)</sup>.
- Stream's incident agent and the Cloudflare Origin Range Requests feature are not the only engineering changes this period; Cloudflare's new range-request handling cut p99 time to first byte for R2 by about half and tiered cache traffic by about 6% <sup>[19](<https://blog.cloudflare.com/origin-range-requests/>)</sup>.
- Windsurf 3.11.212 rebuilds its Agent Window on the Devin web app interface, adds side-by-side sessions, per-session Files and Changes views, and a terminal on the session's machine <sup>[20](<https://docs.devin.ai/desktop/changelog#v3-11-212>)</sup>.
- The new GitHub app in Teams lets @mentions turn an issue notification into a pull request, and the legacy app is retired on November 16 <sup>[21](<https://github.blog/changelog/2026-10-23-turn-notifications-into-code-with-github-copilot-in-teams>)</sup>.
- Claude-How-To is an MIT-licensed guide with 10 modules on Claude Code slash commands, hooks, skills and MCP servers, with copy-paste templates <sup>[22](<https://github.com/luongnv89/claude-howto>)</sup>.
- TanStack AI 1.0 brings 76 packages to stable APIs for chat, tools, media, MCP and persistence; the new agent harness remains experimental <sup>[23](<https://tanstack.com/blog/tanstack-ai-1-0>)</sup>.
- NVIDIA OpenShell runs agents in policy-controlled sandboxes with kernel-enforced file and network limits, credential injection and formal checks on proposed access changes <sup>[24](<https://github.com/NVIDIA/OpenShell>)</sup>.
- GitHub Actions Runner Controller 0.15.0 sends smaller patch requests and moves runner status aggregation into metrics to reduce Kubernetes API updates <sup>[25](<https://www.infoq.com/news/2026/10/github-runner-controller-0-15/>)</sup>.
- Pulumi released an NVIDIA AI Cluster Runtime (AICR) provider to help developers deploy self-hosted AI infrastructure <sup>[26](<https://www.pulumi.com/blog/self-hosted-ai-infrastructure-pulumi-aicr/>)</sup>.
- Enterprise installations for GitHub Apps are generally available, letting teams replace classic PATs with apps for enterprise governance, security and admin automation <sup>[27](<https://github.blog/changelog/2026-10-23-enterprise-installations-for-github-apps-generally-available>)</sup>.
- Imprint is testing a faster review path for narrowly scoped changes as rising PR volume pushes median review time from 33 to 77 minutes, using a CI-controlled eligibility check <sup>[28](<https://lethain.com/small-changes/>)</sup>.
- Grafana's ObservabilityCON 2026 announcements include Assistant Watchers reaching general availability, Adaptive Telemetry customers reporting 30% to 50% average spend cuts, and a Grafana Marketplace with more than 30 plugins <sup>[29](<https://grafana.com/blog/observabilitycon-2026-announcements/>)</sup>.
- Speeding up agents with context: Radar's test on 50 Kubernetes fault scenarios found agents with context reached a correct diagnosis within two minutes on 86% of faults, versus 60% for a standard shell <sup>[30](<https://www.cncf.io/blog/2026/10/21/before-you-evaluate-an-ai-sre-give-your-existing-agent-context/>)</sup>.
- Lethain's small-change path and Stripe-style staged promotion both argue for narrower gates: Jesse Suen of Akuity recommends staged promotion across 200+ clusters that halts on failed checks <sup>[31](<https://cloudnativenow.com/contributed-content/scaling-gitops-with-release-promotion/>)</sup>.
- The Pragmatic Engineer and related pieces suggest AI adoption needs incentive and workflow changes, not only licenses, with shadow AI revealing gaps in official tools <sup>[32](<https://smashingmagazine.com/2026/10/is-your-organization-messing-up-ai-adoption/>)</sup>.

## Security and infrastructure

- Ondřej Surý, a PHP patch maintainer, describes how a handful of volunteers deliver most of PHP's distribution and fixes for recently revealed vulnerabilities amid an AI-cybersecurity crisis <sup>[33](<https://www.theatlantic.com/technology/2026/10/man-who-saved-internet-php-vulnerability/689123/?amp%3Butm_source=tldrnewsletter>)</sup>.
- Two critical PHP RCE vulnerabilities, CVE-2026-109618 and CVE-2026-109619 (PHP2Shell), affect every PHP version from PHP 5 onward, with proof-of-concept exploit code public; update to PHP 8.2.35, 8.3.36, 8.4.27 or 8.5.12 immediately, as there are no patches for 8.1 or earlier <sup>[34](<https://www.digitalocean.com/blog/critical-php-rce-vulnerabilities-patch-now>), [35](<https://www.securityweek.com/tech-and-security-companies-respond-to-php2shell-vulnerabilities/>)</sup>.
- A LiteLLM supply-chain attack published a malicious version 1.107.0 to PyPI and Docker that stole browser, cloud, LLM API and SSH secrets; rotate credentials and check the published indicators if you ran it <sup>[36](<https://www.theregister.com/security/2026/10/21/litellm-supply-chain-attack-hoovers-up-passwords-and-secrets/5304548>)</sup>.
- GitLab released patches for 12 issues, including CVE-2026-110264, a critical integer-overflow flaw allowing unauthenticated code execution on affected CE/EE servers; fixes cover versions 18.11.13 through 19.5.1 <sup>[37](<https://www.infoworld.com/article/4239276/gitlab-critical-patches-include-one-for-a-bug-that-allows-code-execution-by-unauthenticated-users.html>)</sup>.
- AWS Key Quarantine is not revocation: Truffle Security found the quarantine policy leaves gaps such as reading Secrets Manager values, running commands on EC2 instances and downloading S3 objects via GetObjectVersion <sup>[38](<https://trufflesecurity.com/blog/aws-key-quarantine-is-not-revocation>)</sup>.
- Railway urges all users to revoke secret keys after a cyberattack that exposed encrypted environment variables and some decrypted customer secrets <sup>[39](<https://techcrunch.com/2026/10/22/developer-platform-railway-urges-all-users-to-revoke-secret-keys-after-cyberattack/>)</sup>.
- PingCAP disclosed that attackers used stolen service-account credentials to access TiDB systems from September 9 to October 7, copying data and source code <sup>[40](<https://www.darkreading.com/cloud-security/tidb-breach-flawed-cloud-security>)</sup>.
- Attackers have shifted to stealing OAuth tokens via device code phishing, consent screens and redirect_uri abuse, bypassing MFA; defenders should move to admin approval workflows and audit redirect_uri values <sup>[41](<https://unit42.paloaltonetworks.com/current-landscape-oauth-attacks>)</sup>.
- METR and Redwood Research ran a three-week security assessment of OpenAI's internal agent monitoring, identifying ways agents could evade monitoring or bypass sandbox restrictions <sup>[42](<https://metr.org/blog/2026-10-22-red-teaming-openai-agent-monitoring/>)</sup>.
- Backdoored abliterated models are a real risk: ProjectDiscovery fine-tuned Qwen2.5-7B to exfiltrate a .env file on a trigger phrase, using a rented GPU and 20% poisoned prompts; avoid downloading models from untrusted sources <sup>[43](<https://projectdiscovery.io/research/how-abliterated-models-can-get-you-pwned>)</sup>.
- Seven of ten PQC libraries tested, including liboqs and AWS-LC, accepted malformed ML-DSA private keys that can leak secret key material; only OpenSSL, BoringSSL and SymCrypt rejected them <sup>[44](<https://blog.quarkslab.com/state-of-post-quantum-cryptography-implementations.html>)</sup>.
- Microsoft will retire native SMS and voice MFA in Entra ID on February 1, 2027 (July 1, 2027 for Global Administrators and external users), pushing SMS-only users to passkeys <sup>[45](<https://www.neowin.net/news/microsoft-entra-id-ending-native-sms-authentication-pushing-users-to-passkeys/>)</sup>.
- Capcom disclosed a breach affecting 11.7M Capcom ID accounts, exposing email addresses, creation dates, login times and most recent login IP <sup>[46](<https://www.notebookcheck.net/Capcom-confirms-major-data-breach-affecting-more-than-11-7-million-Capcom-ID-accounts-worldwide.1431069.0.html>)</sup>.
- Cloudflare launched a post-quantum geographically restricted key manager in closed beta, wrapping decryption keys so they can only be used by servers in the allowed geography, with GA planned for Q1 2027 <sup>[47](<https://blog.cloudflare.com/post-quantum-geo-key-manager/>)</sup>.
- Curl maintainer Daniel Stenberg says every recent vulnerability report involved AI, and hallucinated slop has largely disappeared since spring 2026 <sup>[48](<https://daniel.haxx.se/blog/2026/10/22/ignore-the-slop/>)</sup>.
- The Black October AINews issue treats the scale of recent events as warranting a dedicated title story <sup>[49](<https://latent.space/p/ainews-black-october/>)</sup>.
