## Models and AI releases

- Thinking Machines has released Inkling 2 Small, a 594B-total, 17B-active Mixture-of-Experts model with image inputs and variable effort, pretrained from scratch in under 3 days on fewer than 12T tokens in native NVFP4 with a single joint RL run, and reported as competitive with, and often beating, same-size Chinese models <sup>[1](<https://latent.space/p/ainews-inkling-2-small-17a-594b-trained-in-68-hours-on-12t-tokens-beating-muse-spark/>)</sup> <sup>[2](<https://thinkingmachines.ai/news/inkling-2-small/>)</sup>. It is initially available through Tinker with closed weights, with full Apache 2.0 weights promised after external safety testing and red-teaming <sup>[2](<https://thinkingmachines.ai/news/inkling-2-small/>)</sup>.
- Gemini Omni 1.2 Flash targets speed, cost-efficiency and longer clip lengths for developers <sup>[3](<https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/>)</sup>.
- NVIDIA introduced VFlash, a vision model that generates geometric predictions such as robot trajectories and 3D motion in parallel rather than token by token <sup>[4](<https://research.nvidia.com/labs/lpr/vflash/>)</sup>.
- Meta announced voice conversations and expressive avatars for its Muse app <sup>[5](<https://about.fb.com/news/2026/11/introducing-muse-ai-voice-expressive-avatars/>)</sup>.

## Developer tools and AI coding assistants

- GitHub's usage metrics API now reports, per repository, how many Copilot code review comments developers acted on, with an addressed rate (addressed comments divided by evaluated comments) and breakdowns by severity, review tier, comment type and customization <sup>[6](<https://github.blog/changelog/2026-11-05-usage-metrics-api-adds-code-review-details-and-addressed-rate>)</sup>.
- The same API now flags users whose client telemetry is missing or whose IDE or Copilot extension versions are below the usage metrics minimums, with daily affected-user counts at enterprise and organization level <sup>[7](<https://github.blog/changelog/2026-11-05-usage-metrics-api-flags-telemetry-and-version-gaps>)</sup>.
- Google analysed over 913,000 coding agent sessions: 13% exposed agents to inline TODO(b/...) comments, and in 6% of those encounters agents acted on them, 83% unprompted, adding 70% more steps, 77% more tokens and 105% more wait time per session; higher-capability models were distracted more often <sup>[8](<https://developers.googleblog.com/agent-distraction/>)</sup>.
- agent-browser is a native Rust CLI that gives AI agents a browser driven one shell command at a time, reading pages as a compact accessibility tree <sup>[9](<https://github.com/vercel-labs/agent-browser>)</sup>.

## Agents and infrastructure for agents

- Google donated Agent Substrate, gVisor and OpenRL to the CNCF Sandbox and made Agent Substrate generally available on GKE; it decouples stateful agent sessions from compute, restoring idle sessions in under 500 ms, with 10x standard container density and over 500 suspend/resume activations per second <sup>[10](<https://cloud.google.com/blog/products/containers-kubernetes/open-infrastructure-for-autonomous-agents-comes-to-cncf/>)</sup>.
- Docker Sandboxes are presented as a distinct technology from containers: dedicated microVMs with their own Linux kernel, filesystem, network and Docker Engine, built for autonomous coding agents, whereas containers share the host kernel <sup>[11](<https://www.docker.com/blog/docker-sandboxes-vs-containers/>)</sup>. Docker also urges isolation and governance for agents over model improvements alone, citing prompt injection, credential exposure and data exfiltration <sup>[12](<https://www.infoq.com/news/2026/11/docker-ai-agent-security/>)</sup>.
- Apache Airflow 3.4.0 adds Task Loops for workflows that repeat until done, authoring Dags in TypeScript, Go, Java or YAML, and a common.ai provider that turns LLM calls and agents into Airflow tasks with human approval <sup>[13](<https://airflow.apache.org/blog/airflow-3.4.0/>)</sup>.
- Pinecone's webinar recap argues that AI agents need more than vector similarity: a relevant result can still give a wrong answer, so decision logic belongs outside the search step <sup>[14](<https://www.pinecone.io/blog/webinar-recap-data-to-vectors-to-context/>)</sup>.
- NVIDIA uses specialized agents to correlate GPU cluster failures across hardware, networking, scheduling and observability, running on-premises with local Nemotron models and read-only Kubernetes credentials <sup>[15](<https://developer.nvidia.com/blog/how-nvidia-uses-ai-agents-to-streamline-ai-factory-operations/>)</sup>.
- An AI FIRST podcast episode describes that company's internal AI operating system, built around one agent with skills rather than 25 specialists, and argues that skills and context decide whether it works <sup>[16](<https://ai-first.ai/podcast/wie-wir-bei-ai-first-mit-ki-arbeiten-blick-hinter-die-kulissen-die-groessten-fehler-und-unser-bestes-ki-setup>)</sup>.

## Security

- Coinspect demonstrated a Firecracker sandbox escape from guest userspace (CVE-2026-122192) that let a guest modify live VMM memory; v1.16.2 and v1.17.0 fix it <sup>[17](<https://www.coinspect.com/blog/firecracker-escape/>)</sup>.
- An OpenSSH password authentication bypass affects Alpine Linux releases 3.16 through 3.24, letting an account with no password set be reached remotely; users should update openssh and restart sshd <sup>[18](<https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/>)</sup>. A related *sshole flaw affects OpenSSH on musl systems without PAM <sup>[19](<https://arstechnica.com/security/2026/11/vulnerability-allows-attackers-to-log-into-some-linux-devices-sans-password/>)</sup> <sup>[20](<https://sshhole.com/>)</sup>.
- OpenAI says an automated pipeline reproduced 1,724 Linux kernel vulnerabilities in 30 hours and generated 948 working local privilege-escalation exploits at about $1,279 each, and advises treating unpatched low-privilege systems as reachable by well-resourced attackers <sup>[21](<https://thehackernews.com/2026/11/openai-ai-pipeline-generates-948-linux.html>)</sup>.
- Bitdefender's GhostMap is an Android flaw where a malformed APK entry crashes system_server into a boot loop; Google declined to ship a fix, so defenders should flag APKs with unusual ZIP compression methods <sup>[22](<https://www.bitdefender.com/en-us/blog/labs/ghostmap-android>)</sup>.
- Anthropic declined to fix a Claude Dispatch flaw that could let a browser extension reach remote code execution in Claude Desktop <sup>[23](<https://www.theregister.com/research/2026/11/05/anthropic-wont-fix-a-claude-dispatch-flaw-that-could-let-attackers-execute-remote-commands-across-corporate-boundaries/5307684>)</sup>.

## Engineering practice and observability

- Grafana Cloud made trace linkage generally available in Database Observability, connecting OpenTelemetry traces to database query data by query <sup>[24](<https://grafana.com/blog/trace-linkage-connect-the-dots-between-your-app-traces-and-database-queries/>)</sup>.
- OpenTelemetry JavaScript SDK 3.0 introduces ESM-only support and drops older Node.js versions <sup>[25](<https://opentelemetry.io/blog/2026/otel-js-sdk-3-0/>)</sup>.
- A K3s platform of more than 15 microservices runs with no centralized log collection, relying on filtered Prometheus metrics and temporary verbose logging, with trade-offs noted for audits <sup>[26](<https://cloudnativenow.com/contributed-content/running-production-with-zero-stored-logs/>)</sup>.
- Google traced intermittent GKE API timeouts to Private Service Connect packet reordering, Envoy half-closed sockets and a Linux TCP bug, fixed in a kernel patch <sup>[27](<https://cloud.google.com/blog/products/networking/the-three-layer-gke-network-mystery>)</sup>.
- AWS Security Hub now offers an organization-wide SBOM inventory across EC2, ECR and Lambda, built from Amazon Inspector <sup>[28](<https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-sbom-inventory/>)</sup>.

## Robotics

- Tau Robotics is running a humanoid cleaning service in San Francisco where robots are piloted remotely by humans, and the collected data is meant to train more autonomous cleaning robots later <sup>[29](<https://www.technologyreview.com/2026/11/06/1148090/i-watched-a-humanoid-robot-clean-my-apartment-it-felt-like-a-taste-of-the-future/>)</sup>.

## Speech and open benchmarks

- OpenAI introduces BioBasicsBench, a 100-task benchmark measuring how well AI agents interpret raw wet-lab experimental data <sup>[31](<https://openai.com/index/measuring-how-ai-agents-handle-wet-lab-science>)</sup>.
