## AI models and releases

- Anthropic released Claude Fable 5.2 and Mythos 5.2, and Fable 5.2 is currently ranked first on Artificial Analysis <sup>[1](<https://simonwillison.net/2026/Nov/9/llm-anthropic/>), [2](<https://latent.space/p/ainews-fable-5-2-retakes-world-1-llm-spot-as-ant-ipo-roadshow-begins/>)</sup>.
- Fable 5.2 is priced at $8 per million input tokens and $40 per million output tokens, down from $10 and $50 for Fable 5.1 <sup>[2](<https://latent.space/p/ainews-fable-5-2-retakes-world-1-llm-spot-as-ant-ipo-roadshow-begins/>)</sup>.
- On the GDPx professional-task benchmark run by SemiAnalysis, Fable 5.2 took first place at 16.4%, but cost rose to $88.15 per task from $67.16 because it wrote far more test cases and spawned subagents to check its work <sup>[2](<https://latent.space/p/ainews-fable-5-2-retakes-world-1-llm-spot-as-ant-ipo-roadshow-begins/>)</sup>.
- Meta launched Muse Ember, its smallest and most efficient model, aimed at tool calls, coding subtasks, routing and extraction; for shorter prompts it is priced the same as GPT-6 Luna and Claude Haiku 5.5 at $0.10 per million input and $0.50 per million output tokens <sup>[3](<https://simonwillison.net/2026/Nov/10/muse-ember/>)</sup>. Meta claims it matches Claude Haiku 5.5's highest reasoning score at roughly one-third the cost and outperforms GPT-6 Luna across reasoning settings <sup>[4](<https://research.meta.ai/blog/muse-ember>)</sup>.
- Google made Gemini 4 Carbon generally available, priced at $2 per million input and $10 per million output at launch, scheduled to double to $4 and $20 on December 1; it is also in GitHub Copilot for Pro+, Max, Business and Enterprise users <sup>[5](<https://github.blog/changelog/2026-11-10-gemini-4-carbon-in-github-copilot>), [6](<https://simonwillison.net/2026/Nov/10/llm-gemini/>), [7](<https://deepmind.google/blog/gemini-4-carbon-is-now-available/>)</sup>.
- Anthropic's documentation says that telling Fable 5.2 the codebase is its own made it merge repeated code in about half of tries, versus under a tenth without that statement <sup>[8](<https://simonwillison.net/2026/Nov/10/prompting-claude-fable-52/>)</sup>.
- Anthropic reports that a team of 1,000 Fable 5.2 agents reproduced a formal proof of Fermat's Last Theorem in 28.7 hours, using separate sandboxes, shared Git and a SQL database for coordination, with one-third the output tokens of the earlier formalization <sup>[9](<https://claude.dev/blog/safely-scaling-multi-agent-teams-with-fable-5-2/>)</sup>.
- Anthropic tested Fable 5.2 on electronics design: it produced a speakerphone, a voice-assistant hub and a virtual pet, with human engineers building working prototypes, but the devices have not undergone electrical validation, antenna tuning, thermal testing or certification <sup>[10](<https://www.anthropic.com/research/claude-electronics-design>)</sup>.

## Agents, RAG and tooling

- The llm-anthropic 0.31 release adds Fable 5.2 support, but the max reasoning setting failed to return an image because it ran out of tokens after 128,000 thinking tokens <sup>[1](<https://simonwillison.net/2026/Nov/9/llm-anthropic/>)</sup>.
- Anthropic's Claude Whiteboards, Sheets and Data are in beta or generally available on paid plans, with interactive connectors that let partner apps open inside Claude so Claude can make changes directly <sup>[11](<https://claude.com/resources/articles/sheets-whiteboards-data>), [12](<https://claude.com/resources/articles/more-ways-to-work-with-claude-sheets-whiteboards-and-interactive-connectors>), [13](<https://claude.com/resources/articles/interactive-connectors-full-tool>)</sup>.
- Storybook 11 beta adds official skills and headless CLI tools so agents can iterate autonomously on components <sup>[14](<https://storybook.js.org/blog/storybook-11-beta/>)</sup>.
- GitHub's C++ language server for Copilot CLI now bundles its MSBuild compile-commands extractor, so agents no longer need a separate configuration step <sup>[15](<https://github.blog/changelog/2026-11-10-c-language-server-now-auto-configures-msbuild-builds>)</sup>.
- Pinecone integrated embedding now supports OpenAI's text-embedding-3-small and -large, so teams can send plain text without managing an embedding pipeline <sup>[16](<https://www.pinecone.io/blog/integrated-embedding-openai/>)</sup>.
- Hugging Face introduced decision models that return typed outputs with probabilities for narrow questions before calling an LLM <sup>[17](<https://huggingface.co/blog/decision>)</sup>; PostHog reports its personal-data filter built on this approach skips 98.7% of LLM calls <sup>[18](<https://newsletter.posthog.com/p/decision-models>)</sup>.
- Reticle gives coding agents runtime visibility into an app through an SDK and MCP tools covering interactions, network traffic, state and console activity <sup>[19](<https://github.com/reticlehq/reticle>)</sup>.

## LLM tooling and developer workflows

- A developer built Beep Locator with Claude Code, a multi-device system that triangulates a beep's source from phones and tablets acting as listeners <sup>[20](<https://simonwillison.net/2026/Nov/9/mysterious-beeps/>)</sup>.
- GitHub used the Copilot app to port almost 800K lines of Copilot engine code from TypeScript to Rust, after the existing design consumed too many resources <sup>[21](<https://blog.bytebytego.com/p/how-github-used-ai-to-port-copilot>)</sup>.
- Dropbox used scoped AI agent tasks to deliver 22 accessibility improvements and clear a backlog of 53 test cleanup tasks in a week, with engineers reviewing the results <sup>[22](<https://dropbox.tech/machine-learning/how-aiassisted-development-helped-us-build-the-new-dropbox-experience>)</sup>.
- ExecuTorch's new WebGPU backend runs the same torch.export .pte file on the GPU in any WebGPU browser, 4–7× faster than its CPU path on prefill and 2–10× faster on decode <sup>[23](<https://pytorch.org/blog/executorch-webgpu-pytorch-models-on-the-gpu-in-the-browser/>)</sup>.

## Data engineering

- DuckDB's columnar storage means a query touching three of fifty columns reads only those three; values are processed in vectors of 2,048 and compress well because each column holds one type <sup>[24](<https://duckdb.org/2026/11/10/ducks-in-a-column.html>)</sup>.

## Infrastructure, cloud and security

- Google introduced TPU 8i Max for long-context workloads and TPU 8tx for secure, confidential inference <sup>[25](<https://blog.google/innovation-and-ai/infrastructure-and-cloud/global-network/tpu-8i-max-and-8tx/>), [26](<https://www.bloomberg.com/news/articles/2026-11-09/google-escalates-nvidia-rivalry-with-new-versions-of-its-tpu-systems?amp%3Butm_source=tldrnewsletter>)</sup>.
- Hugging Face Hub can now be paid through a linked Google Cloud Marketplace account, so usage appears on the existing Google Cloud bill <sup>[27](<https://huggingface.co/blog/hub-gcp-marketplace>)</sup>.
- Wiz reports an attacker abused Qubole's AWS cross-account roles from October 14 to 26; customers should check CloudTrail, delete unused vendor roles and pin trust policies with an aws:SourceIp condition <sup>[28](<https://www.wiz.io/blog/qubole-cross-account-access-abused-in-the-wild>)</sup>.
- QNAP warns that four Plex2Shell vulnerabilities are being actively exploited on NAS devices running a public Plex server; it advises treating exposed devices as compromised <sup>[29](<https://www.bleepingcomputer.com/news/security/qnap-says-hackers-breaching-nas-devices-in-plex2shell-attacks/>)</sup>.
- SonicWall disclosed an SSL-VPN MFA bypass that CISA added to KEV, and fixed six other vulnerabilities <sup>[30](<https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-new-ssl-vpn-mfa-bypass-flaw-exploited-in-attacks/>)</sup>.
- Dependabot alerts will pause on repositories with no activity in the past year from December 8, with archived alerts restorable at any time <sup>[31](<https://github.blog/changelog/2026-11-10-dependabot-alerts-will-pause-on-inactive-repositories>)</sup>.
