## Models and LLM tooling

- Mercor raised a $750m Series D at a $20B valuation, reporting a $3B annualized run rate and 5 million experts on its network <sup>[1](<https://latent.space/p/ainews-mercor-750m-series-d-at-20b-valuation-3b-run-rate/>)</sup>. The company says it spends 3x as much on inference as on employee salaries <sup>[1](<https://latent.space/p/ainews-mercor-750m-series-d-at-20b-valuation-3b-run-rate/>)</sup>.
- Google released Gemini 4 Carbon to all paying developers and enterprises through the API, rolling out to Google AI Ultra subscribers in Antigravity, the Gemini app and AI Mode in Search <sup>[2](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/>)</sup>. Google says it ranks first on CursorBench 4.0, Perplexity's WANDR and Zapier's AutomationBench at more than 2x lower cost per task than the next best external model, at the same $2/$10 per million input/output token price as Gemini 4 Argon <sup>[2](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/>)</sup>.
- Google launched the Gemini Decisions API with yes/no, choice and rubric-scoring questions, priced at 10 cents per million input tokens with free output, and multimodal across text, images, audio, video and PDFs <sup>[3](<https://simonwillison.net/2026/Nov/11/gemini-decisions-api/>)</sup>.
- BotPsy, a sub-billion-parameter agentic language model aimed at on-device personal assistant use, is presented with benchmark results on tool use, knowledge, instruction following and multi-turn conversations <sup>[4](<https://huggingface.co/blog/qvac/botpsy>)</sup>. Its authors argue small specialized agents can match frontier models on specific tasks at much lower cost and with better privacy <sup>[4](<https://huggingface.co/blog/qvac/botpsy>)</sup>. Multi-step information retrieval is reported as its weak spot <sup>[4](<https://huggingface.co/blog/qvac/botpsy>)</sup>.
- MAI-Transcribe-2 is presented as a speech recognition model that is faster, more accurate and cheaper than several leading models, with diarization and word-level timestamps, at $0.10 per hour of audio <sup>[5](<https://microsoft.ai/news/mai-transcribe-2-is-the-fastest-most-accurate-and-cheapest-speech-recognition-model-in-the-world/>)</sup>.
- Goodfire argues that individual language-model neurons are more interpretable than commonly assumed, using Neuron Scientist agents to generate and test neuron descriptions <sup>[6](<https://www.goodfire.com/research/neurons-as-an-interpretable-basis>)</sup>.

## Agents, coding tools and developer workflows

- At the AI Engineer Code Summit, OpenAI ran a workshop on new ways of working with Codex, covering cloud execution, personal agents between sessions and voice steering of coding tasks <sup>[7](<https://latent.space/p/codex-work/>)</sup>. The write-up notes the shift to cloud is still confusing for many users of Codex, Claude and Antigravity <sup>[7](<https://latent.space/p/codex-work/>)</sup>.
- Google Antigravity's /swarm command runs a team of named agents that split tasks, work in parallel and coordinate on a shared message board, available on AI Pro and Ultra plans <sup>[8](<https://antigravity.google/docs/swarm/>)</sup>.
- AWS released an official local emulator for its services, written in Rust, to run tests without a paid API key; it currently requires Docker on macOS and Windows <sup>[9](<https://simonwillison.net/2026/Nov/11/aws-emulator/>)</sup>.
- Sentry is combining its CLI and MCP server so agents share CLI authentication while keeping native tool discovery <sup>[10](<https://x.com/zeeg/status/2120224571689484639>)</sup>.
- A2UI 1.0 is an open protocol for generative UI that lets agents render native interfaces across web, mobile and desktop, with bidirectional function calls and renderer SDKs for several frameworks <sup>[11](<https://developers.googleblog.com/a2ui-10-build-delightful-fast-reliable-agentic-experiences/>)</sup>.
- Modern Web Guidance 1.0 embeds web platform expertise and browser compatibility data into coding agents, with Firefox and Edge joining Chrome in supporting it <sup>[12](<https://developer.chrome.com/blog/modern-web-guidance-v1>)</sup>.
- Heavy AI coding can produce shallow tests, unnecessary abstractions and pull requests that outrun reviewers, leading to more incidents and slower recovery <sup>[13](<https://evanxmerz.com/post/ai-usage-generates-a-fragile-codebase/>)</sup>.
- Kubernetes can restore an AI agent's environment but cannot record which steps finished, so restarted agents may repeat actions such as payments; the author argues for durable execution <sup>[14](<https://cloudnativenow.com/contributed-content/kubernetes-gave-ai-agents-a-place-to-run-but-not-a-way-to-recover/>)</sup>.
- GitHub now lets enterprise GitHub Apps call the enterprise-level Copilot seat management APIs, using a new fine-grained permission <sup>[15](<https://github.blog/changelog/2026-11-10-github-app-support-for-enterprise-copilot-seat-management>)</sup>.

## Infrastructure, MLOps and DevOps

- GKE dynamic slicing for TPUs is now generally available, separating slice formation from nodepool provisioning and cutting AI workload startup times by up to 5x and recovery times by 4.5x <sup>[16](<https://cloud.google.com/blog/products/containers-kubernetes/gke-dynamic-slicing-on-tpus/>)</sup>.
- AWS Nitro Sandboxes runs each Amazon EKS pod inside its own lightweight virtual machine for hardware-enforced isolation, enabled with one line in the pod spec, with an isolated mode and a confidential mode with attestation <sup>[17](<https://aws.amazon.com/blogs/containers/aws-nitro-sandboxes-hardware-enforced-workload-isolation-on-amazon-eks/>)</sup>.
- CloudNativePG has moved from CNCF Sandbox to Incubation; the operator runs highly available PostgreSQL on Kubernetes and manages pods directly rather than through StatefulSets <sup>[18](<https://www.cncf.io/blog/2026/11/10/cloudnativepg-becomes-a-cncf-incubating-project/>)</sup>.
- Cost Intelligence for Argo CD is an open-source extension that shows each application's cost using the previous 24 hours of OpenCost data after each sync <sup>[19](<https://octopus.com/blog/argocd-cost-intelligence>)</sup>.
- An open field guide maps platform engineering skills onto production inference, covering GPU memory, KV caches, serving engines, observability and costs <sup>[20](<https://docs.modelplane.ai/guides/inference-guide>)</sup>.

## Data, retrieval and cost control

- A dbt team reports cutting more than 50% off token costs by storing agent context directly in the data warehouse rather than retrieving it dynamically <sup>[21](<https://www.getdbt.com/blog/economic-case-warehouse-first-ai-context>)</sup>.
- Iceberg's REST catalog protocol puts commit logic behind a common interface, and the article argues users need a verifiable definition of openness to judge lock-in <sup>[22](<https://www.dataengineeringweekly.com/p/how-open-is-open-iceberg-catalogs>)</sup>.

## Security

- Google patched an eighth Chrome zero-day exploited in attacks this year, a use-after-free bug in the XML parser that can lead to arbitrary code execution <sup>[23](<https://www.bleepingcomputer.com/news/security/google-patches-eighth-chrome-zero-day-exploited-in-attacks-this-year/>)</sup>.
- N-able disclosed 33 zero-days in N-central, with proof-of-concept exploits; it took hosted environments offline, and watchTowr observed exploitation attempts against honeypots <sup>[24](<https://thehackernews.com/2026/11/n-able-takes-hosted-n-central-offline.html>)</sup>.
- Barracuda reported two actively exploited ESG appliance flaws that allow root command execution, requiring access to the administrative console <sup>[25](<https://www.bleepingcomputer.com/news/security/hackers-exploit-barracuda-email-security-gateway-flaws-to-get-root-access/>)</sup>.
- LLM 0.37.2 fixes two issues that could accidentally send a configured OpenAI API key to another provider <sup>[26](<https://simonwillison.net/2026/Nov/11/llm/>)</sup>.
