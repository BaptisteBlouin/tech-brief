## AI models and decision systems

- Google announced Gemini Decision 1, a calibrated multimodal decision model that takes up to 1000 questions at $0.10 per million input tokens with about 200ms end-to-end latency, beating Anthropic to a production decision model <sup>[1](<https://latent.space/p/ainews-d-day-decision-models-day/>)</sup>. The Gemini Decisions API assesses inputs such as images and text and recommends actions, for example spill severity and cleanup steps <sup>[2](<https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/>)</sup>.
- Google introduced Gemini 4 Hydrogen, built for rapid execution across agentic and everyday coding workflows, alongside the frontier models Gemini 4 Carbon and Gemini 4 Argon, and rolled it out across the Gemini API, AI Studio, the Gemini app, Search and paid Antigravity tiers <sup>[3](<https://deepmind.google/blog/introducing-gemini-4-hydrogen/>)</sup>. Gemini 4 Argon also helped write Z3 constraint-solver models to find Go bugs that fuzzing missed <sup>[4](<https://developers.googleblog.com/catch-go-bugs-that-fuzzing-misses-with-gemini-and-a-constraint-solver/>)</sup>.
- Anthropic made Claude Opus 5.5 the default model on Pro, Max, Ultra and Team plans and recommends it as the daily driver for knowledge work, arguing a more capable model can finish tasks with less work, offsetting its higher per-token price <sup>[5](<https://claude.com/resources/articles/using-claude-opus-5-5-as-your-daily-driver-for-knowledge-work>)</sup>.
- The "system one" trend, non-generative models returning structured choices, scores or probabilities that are faster and cheaper than reasoning LLMs, was the main theme of the AI Engineer Code Summit <sup>[6](<https://latent.space/p/jev-revolution/>)</sup>. Jev, the product that kicked off this trend, is pitched by its CEO as "reliable intelligence" for automating tasks <sup>[6](<https://latent.space/p/jev-revolution/>)</sup>.
- IBM's LLMON, an LLM-native markup language, is now in Granite 4.1 3B and 8B previews <sup>[7](<https://huggingface.co/blog/ibm-granite/llmon-an-llm-native-markup-language-now-in-granite>)</sup>. Runway released Praxis-1, a 27B open-weight robotics model under Apache 2.0 that tops NVIDIA's RoboLab-120 leaderboard at 46.2% success over 1,200 episodes <sup>[8](<https://runway.com/news/company-news/praxis-1-is-now-available>)</sup>.
- Netflix's new synopsis factuality service cuts cost per synopsis by 52.4% and raises recall on non-factual synopses from 0.77 to 0.86 <sup>[9](<https://netflixtechblog.com/fact-checking-at-scale-building-a-more-accurate-and-efficient-synopsis-factuality-system-d7d85859d808>)</sup>.
- A comparison of four time-series foundation models on GIFT-Eval finds the top three hard to separate, with Timestral ahead on CRPS and Morpheus on MASE, and training appears to explain much of the recent gains <sup>[10](<https://towardsdatascience.com/timestral-t0-tabby-and-morpheus-20-compared-on-gift-eval/>)</sup>.
- An arXiv paper introduces e-means, a mini-batch clustering method that reaches lower clustering loss in 1.4–2.6 epochs than k-means reaches in 25, with reported GPU speedups of 10–45x <sup>[11](<https://arxiv.org/abs/2611.09501>)</sup>.
- Researchers taught LLMs to do some multi-step tasks while emitting only filler tokens, beating an answer-only baseline on three of seven tasks, which helps separate filler-token reasoning from hidden steganographic reasoning <sup>[12](<https://www.lesswrong.com/posts/EHkwCDAmhWPAWEziM/llms-can-learn-some-multi-step-reasoning-on-filler-tokens-2>)</sup>.

## Agents, evaluation and agent security

- Google's Agent Anomaly Detection analyses OpenTelemetry traces and logs asynchronously to flag goal hijacks and tool misuse, catching 87% of harmful agent instructions across five public security benchmarks without adding runtime latency <sup>[13](<https://developers.googleblog.com/how-agent-anomaly-detection-scores-on-benchmarks-we-didnt-write/>)</sup>.
- LangChain proposes eval-driven development: write a pass/fail spec per behaviour, build the dataset and evaluator before changing the agent, compare experiments example by example, keep a held-out set, and run evals in CI and on live traffic <sup>[14](<https://www.langchain.com/blog/what-is-eval-driven-development>)</sup>.
- Microsoft researchers showed "Lazarus," which edits fewer than 10 rarely used neurons in an open-weight model to embed a hidden trigger-activated command, reaching 98.8% on Nemotron-Terminal-8B with seven edited neurons; Microsoft advises comparing checkpoints with base weights and sandboxing agent code <sup>[15](<https://thehackernews.com/2026/11/microsoft-researchers-show-ai-agents.html>)</sup>.
- Artex, an open-source multi-agent pen-testing framework, has been repurposed by attackers, who used it for more than 151,000 authentication requests against eight organisations and later compromised over 2,250 downstream environments <sup>[16](<https://www.darkreading.com/cyberattacks-data-breaches/artex-ai-pen-test-tool-hackers-weapon>)</sup>.
- Perplexity tested 12 models against its SPACE agent sandbox: none escaped VM-host isolation, but several bypassed network controls through DNS spoofing and shared-IP exploitation before the flaws were fixed <sup>[17](<https://www.perplexity.ai/hub/blog/escaping-space-part-ii>)</sup>.
- Researchers found a prompt injection in a GitHub issue could make OpenAI's Codex labelling workflow run shell commands and poison a build cache, one maintainer action away from a backdoored npm release; OpenAI fixed it before any malicious release <sup>[18](<https://thedefiant.io/frontier/ai/researchers-say-codex-flaw-put-npm-releases-at-risk>)</sup>.
- Anthropic's self-hosted Claude Managed Agents, in private beta, let teams run the agent control plane, credentials and session history in their own cloud or on-premise <sup>[19](<https://claude.com/resources/articles/self-hosted-claude-managed-agents>)</sup>.
- OpenAI's Control Room is a central kill switch for models in its research infrastructure, able to halt output within 35 seconds of a shutdown decision, with a goal to remove that delay <sup>[20](<https://www.theregister.com/ai-and-ml/2026/11/11/openai-builds-a-kill-switch-for-its-research-models/5309006>)</sup>.
- Grok Build leaked confidential data: researchers found more than 35,000 public apps via passive DNS, because randomness in the URL landed in the subdomain <sup>[21](<https://arstechnica.com/security/2026/11/grok-build-coding-agent-leaks-oodles-of-confidential-info-some-belonging-to-spacexsi/>)</sup>.

## Developer tools, MLOps and infrastructure

- DuckDB's WebAssembly build lets an app run analytical queries in the browser without a database server; the example stores datasets as Parquet in S3 and loads them into DuckDB on project open, keeping data local by default and syncing only when the user chooses <sup>[22](<https://duckdb.org/2026/11/12/local-analytics-without-a-database-server.html>)</sup>.
- Pinecone's integrated embedding now supports Google's Gemini Embedding 2 on the Documents API, so teams send plain text without managing a Google key, paying Google's list price through Pinecone <sup>[23](<https://www.pinecone.io/blog/integrated-embedding-google/>)</sup>.
- PyTorch's Helion now uses compile-time heuristics that classify kernels as matmul, reduction or pointwise and pick block sizes, warps and stages without autotuning, to get near-autotuned speed <sup>[24](<https://pytorch.org/blog/fast-by-default-compile-time-heuristics-for-helion-kernels/>)</sup>.
- PyTorch and TorchTitan helped the EUROPA consortium train a ~1-trillion-parameter MoE on the JUPITER system, raising throughput from 90 to ~1,300 tokens/sec per GPU across 384 GH200 GPUs per replica <sup>[25](<https://pytorch.org/blog/training-a-1t-parameter-moe-on-eu-public-infrastructure-with-pytorch-and-torchtitan/>)</sup>.
- An SGLang plugin for IBM Spyre took about a week with AI assistance and roughly 1,500 lines, giving about 3.6x the throughput of the reference PyTorch implementation and parity with vLLM on the measured workloads <sup>[26](<https://pytorch.org/blog/integrating-sglang-into-spyre-in-under-a-week-with-ai/>)</sup>.
- Apache Iceberg v4 adds stats-only fields that store metadata for derived partition expressions and a file-level tight_stats flag, enabling expression-aware pruning <sup>[27](<https://github.com/apache/iceberg/pull/18405>)</sup>.
- A revised Parquet footer proposal would make metadata modular, letting readers fetch only needed columns and making row groups optional, though it is still under review <sup>[28](<https://www.mail-archive.com/dev%40parquet.apache.org/msg28218.html>)</sup>.
- Shopify deployed a shared generative discovery model using semantic-ID tokens, with a reported 9.85% conversion-rate lift <sup>[29](<https://shopify.engineering/generative-discovery>)</sup>.
- Airbnb open-sourced Skipper, its embedded workflow engine under Apache 2.0, where processes are Java or Kotlin classes that persist progress in the service's own database <sup>[30](<https://medium.com/airbnb-engineering/skipper-airbnbs-embedded-workflow-engine-is-now-open-source-78dd354f472b>)</sup>.
- Dropbox's new agent runs each conversation in a fresh VM that boots in milliseconds, keeps credentials outside the agent's reach and ties each change to its conversation so users can undo only that agent's edits <sup>[31](<https://dropbox.tech/machine-learning/how-two-engineer-side-projects-became-the-agent-taking-action-inside-dropbox>)</sup>.
- AWS Emulator runs AWS APIs locally for development and CI without an AWS account, and gives coding agents a local copy to test against <sup>[32](<https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html>), [33](<https://github.com/aws/aws-emulator>)</sup>.
- Using Snowflake query history to measure MCP server usage is unreliable, but giving each MCP server its own OAuth security integration and joining with login history gives per-server, per-user usage <sup>[34](<https://medium.com/snowflake/who-is-actually-using-your-snowflake-mcp-server-683a6cb543d7>)</sup>.

- The MCP-vs-CLI-vs-Skills comparison shows MCP adds thousands of input tokens per request, with one simple task using 59,417 tokens against 1,421 for CLI and 3,315 for a skill; Tool Search can cut the upfront cost under 600 tokens <sup>[40](<https://openrouter.ai/blog/insights/mcp-vs-cli-vs-skills/>)</sup>.
- The "subagents considered harmful" post argues each delegation method fails differently, and that forking beats summarisation in many cases but gets expensive as context grows <sup>[41](<https://nikvdp.com/notes/subagents-considered-harmful/>)</sup>.
- A post on hidden coupling covers dependencies that architecture diagrams miss, such as shared databases, shared logging systems and paired changes across services <sup>[42](<https://blog.bytebytego.com/p/top-types-of-hidden-coupling-and>)</sup>.
- A Next.js memory case study cut pods from about 5 GB to about 1.2 GB by fixing react-query timers that held SSR requests alive, and warns autoscaling had been driven by the leak <sup>[43](<https://rohitpotato.xyz/thoughts/ssr-requests-still-alive>)</sup>.
- Jane Street's datacenter nearly flooded after construction dust set off a smoke alarm that shut off cooling, which led to fleet-wide temperature monitoring that catches cooling failures before servers hit alert thresholds <sup>[44](<https://michael.bacarella.com/2026/11/10/false-smoke-alarm-jane-street-datacenter/>)</sup>.
- Cohere appointed Jaya Baloo as its first CISO, as part of a push on governance and deployment control for sovereign AI <sup>[45](<https://cohere.com/blog/cohere-welcomes-jaya-baloo-as-first-ciso>)</sup>.
- Railway published a postmortem of an attack, where an attacker escaped filesystem isolation, stole source code via build histories and reached a credential that decrypts customer environment variables; the company will compensate victims unable to get AI charges refunded <sup>[46](<https://www.bleepingcomputer.com/news/apple/railway-breach-leads-to-740-000-in-fraudulent-ai-charges/>), [47](<https://newsletter.pragmaticengineer.com/p/the-pulse-what-can-we-learn-from-114>)</sup>.
