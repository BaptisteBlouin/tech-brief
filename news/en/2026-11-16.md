## Developer tools and data tooling

- Datasette 1.0a43 adds streaming support for output renderers, so plugins can stream every row of a table in one pass via a new `Response.stream()` method <sup>[1](<https://simonwillison.net/2026/Nov/15/datasette/>)</sup>. It also fixes a security issue where private stored queries could expose their title and SQL (not executable) <sup>[1](<https://simonwillison.net/2026/Nov/15/datasette/>)</sup>.
- A backported 0.65.6 release fixes a security issue where a database registered with a route differing from its name could be downloaded by actors denied access to it <sup>[2](<https://simonwillison.net/2026/Nov/15/datasette-2/>)</sup>.
- datasette-maplibre 0.1a0 is a new Datasette geospatial plugin combining MapLibre GL with OpenFreeMap; it renders SVG previews of GeoJSON shapes and loads WebGL previews only when they scroll into view <sup>[3](<https://simonwillison.net/2026/Nov/15/datasette-maplibre/>)</sup>.
- db-branch is a self-hosted, open-source tool that creates isolated MySQL and PostgreSQL database copies in seconds, sharing existing storage until changes are made, so developers and AI agents can test queries and migrations without touching production data <sup>[4](<https://github.com/db-branch/db-branch>)</sup>.

## Data engineering and the modern data stack

- Data Engineering Weekly discusses the renewed interest in ontologies and knowledge graphs as AI agents raise their business value <sup>[5](<https://www.dataengineeringweekly.com/p/data-engineering-weekly-296>)</sup>.
- PostHog argues the modern data stack era is ending, with data catalogs moving toward context engines <sup>[5](<https://www.dataengineeringweekly.com/p/data-engineering-weekly-296>)</sup>.
- GoDaddy describes building an AI agent for data pipeline creation <sup>[5](<https://www.dataengineeringweekly.com/p/data-engineering-weekly-296>)</sup>.
- NVIDIA's Apache-licensed Auto Ontology turns database metadata into a semantic graph that humans can review and certify and agents can access over MCP, API or CLI, aiming to make natural-language analytics more consistent and auditable than direct text-to-SQL <sup>[6](<https://github.com/NVIDIA/auto-ontology>)</sup>.

## LLMs, models and AI research

- Hugging Face and OpenRouter are teaming up so that every open-weight model on the Hub that a provider serves can be called with a Hugging Face token; Inference Providers switches from its custom router to OpenRouter, which picks a provider per request based on live price, speed and reliability, and retries on another provider if one fails <sup>[7](<https://huggingface.co/blog/openrouter>)</sup>.
- Qwen4-Max is presented as a general-purpose model for 3D modeling, game development, finance, law, healthcare and scientific discovery, with smaller models in the family coming to open source <sup>[8](<https://qwen.ai/blog?id=qwen4-max&amp;utm_source=tldrai>)</sup>.
- GitHub Copilot deprecated Claude Opus 4.8 and Claude Opus 5 on November 16, 2026, with Claude Opus 5.5 suggested as the replacement, and GPT-5.6 Terra is also deprecated in favour of GPT-6.1 Sol or GPT-6 Luna <sup>[9](<https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026>)</sup>.
- Black Forest Labs trained FLUX 3 on images, video and audio together, and explains what a still image, a moving camera and a soundtrack each contribute during training <sup>[10](<https://latent.space/p/why_flux_3_trains_on_images_video_and_sound_andreas_blattmann_dustin_podell_black_forest_labs/>)</sup>.
- Quark is a language model of about 165 million parameters trained for about $4,200 of compute, reported to have the best benchmark average among open models of its size trained on similar token budgets <sup>[11](<https://empero.org/writing/quark>)</sup>.
- Embla 1 is a reasoning model built for phones, reported to run privately and offline on-device, averaging 57.4 across five benchmarks at 4-bit and answering in 1.77 seconds end-to-end on an iPhone 18 Pro <sup>[12](<https://sevren.ai/blog/embla-1>)</sup>.
- SparseRead is a training-free control layer that decides how much of a file, webpage or repository enters an agent's context; the authors report lower token use and latency across six models and five workloads without changing the model <sup>[13](<https://arxiv.org/abs/2608.22237>)</sup>.

## AI agents, MLOps and infrastructure

- Agent Substrate, distributed as kagent 1.0 GA for running AI agents on Kubernetes, schedules agents as actors on warm worker pools, suspending idle actors and restoring them on demand; Agent Substrate is now a CNCF project <sup>[14](<https://www.solo.io/blog/announcing-kagent-1-0-ga>)</sup>.
- Google's guide on agent sessions argues that session-per-Pod allocation wastes cluster resources, and that parking idle sessions in object storage with Agent Substrate and AX on GKE can cut Kubernetes node costs by up to 40% <sup>[15](<https://developers.googleblog.com/agents-are-sessions-not-requests-size-gke-node-pools-for-ai-agent-sessions/>)</sup>.
- Google Cloud open-sourced TPU Sync, a C++ library that moves KV cache blocks and model weights between TPU memory, host memory and storage, cutting median KV transfer latency for Qwen3 235B from several seconds to about 230 ms <sup>[16](<https://www.infoq.com/news/2026/11/google-tpu-sync/>)</sup>.
- Gang scheduling and topology-aware placement, implemented by Kueue and the Coscheduling plugin, address distributed AI training needs that Kubernetes' default per-pod scheduler cannot meet <sup>[17](<https://www.cncf.io/blog/2026/11/12/gang-scheduling-and-topology-aware-placement-for-ai-training-in-kubernetes/>)</sup>.
- Pinterest's Analytics Agent sometimes skipped required steps; after manual edits left one rule at 64% compliance, the team used loop engineering (propose a change, test it on paired suites, keep what works) and reached 89.3% compliance, though 10.3% of cases changed verdict between runs <sup>[18](<https://medium.com/pinterest-engineering/how-pinterest-improved-analytics-agent-compliance-with-loop-engineering-d3c52d0abaa2>)</sup>.
- Google's Agent Anomaly Detection on the Gemini Platform reads the traces and logs agents already produce and flags sessions where an agent goes outside its intended job; the post walks through a hands-on test setup <sup>[19](<https://developers.googleblog.com/securing-your-agents-a-hands-on-guide-to-agent-anomaly-detection/>)</sup>.
- Google's guide to TPU model design gives hardware-grounded rules on shape alignment, architectural choices such as LatentMoE and parallelism strategies for LLMs and MoE models on Ironwood (TPU v7x) <sup>[20](<https://developers.googleblog.com/tpu-model-design-considerations-and-optimization-guide/>)</sup>.
- Google's stable on-policy RL work on TPU addresses numerical mismatch between the sampler and trainer that can destabilize RL training for LLMs <sup>[21](<https://developers.googleblog.com/unlocking-stable-on-policy-rl-on-tpu-with-bitwise-zero-traininference-mismatch/>)</sup>.
- Docker Sandboxes' Firecrawl kit gives sandboxed coding agents live web search, scraping and crawling through a single added host, returning clean markdown, so agents can read current docs without widening the sandbox allowlist <sup>[22](<https://www.docker.com/blog/docker-sandboxes-firecrawl-web-access/>)</sup>.
- Shopify's Cyber Chaos Monkey is an agentic vulnerability hunter that attacks live production systems with read-only ephemeral credentials, an egress allowlist and a separate judge agent on a different model that ends a run if it breaks the rules of engagement <sup>[23](<https://shopify.engineering/cyber-chaos-monkey>)</sup>.

## Developer workflow and software engineering

- Teams using AI coding agents face CI that can't keep pace with generated code; the proposed fixes are to measure slow steps, cache dependencies, use faster runners, parallelize jobs and tests, and skip redundant work with path filters and cancellation <sup>[24](<https://tldr.tech/dev/2026-11-16>)</sup>.
- GitHub Copilot's weekly releases bring GitHub Enterprise Server repositories into the Copilot app, let users continue cloud and Codespace sessions on mobile, and add Gemini 4 Carbon and Claude Fable 5.2 to the model list <sup>[25](<https://github.blog/changelog/2026-11-16-github-copilot-weekly-releases-november-9>)</sup>.
- Devin Apps lets teams describe private web apps (dashboards, approval queues) that Devin builds and hosts, using the team's existing integrations and codebase, with sign-in required for viewers <sup>[26](<https://devin.ai/blog/devin-apps>)</sup>.
- Software engineering after cheap code, a conversation with Satya Nadella, discusses how the discipline changes once writing code costs little <sup>[27](<https://newsletter.pragmaticengineer.com/p/software-engineering-after-code-becomes>)</sup>.
- Cohere's Compass adds Video Intelligence, which lets AI applications search video collections, retrieve timestamped moments with transcripts and visual descriptions, and is now recruiting design partners <sup>[28](<https://cohere.com/blog/video-intelligence-preview>)</sup>.
- AI-generated code and the public domain: one essay argues that code produced by AI should be released under open-source licenses or dedicated to the public domain, since the models depend on collectively produced code <sup>[24](<https://tldr.tech/dev/2026-11-16>)</sup>.

## Security

- Anthropic shortens its coordinated vulnerability disclosure window from 90 to 30 days for high- and critical-severity issues, and to 45 days for others, for reports made on or after January 1, 2027 <sup>[29](<https://www.anthropic.com/research/coordinated-vulnerability-disclosure-timelines>)</sup>.
- Google Project Zero replaces its "90 + 30" policy with a "Full X" model that discloses bugs a fixed number of days after reporting, starting at 90 days and moving to 60 on February 2, 2027 and to 30 on January 3, 2028 <sup>[30](<https://projectzero.google/2026/11/disclosure-policy.html>)</sup>.
- Apache fixed CVE-2026-119618, a critical heap corruption flaw in mod_http2 that can lead to remote code execution, in HTTP Server 2.4.71 on November 11; it affects 2.4.55 through 2.4.70 and needs no authentication to exploit <sup>[31](<https://webflow.sysdig.com/blog/httpd-cve-2026-119618-detecting-heap-corruption-and-rce-in-apache-http-server-mod-http2>)</sup>.
- Arctic Wolf linked the open-source AntiFox AI pentesting platform to intrusions that extracted AWS credentials and reached production Secrets Manager values, with AWS stating its services were not compromised and recommending least privilege, IMDSv2 and removing long-term keys from application configurations <sup>[32](<https://thehackernews.com/2026/11/antifox-ai-pentesting-platform-linked.html>)</sup>.
- OpenAI's Daybreak Defense Factory turns security findings into engineer-ready patches, ingesting findings from security tools and its red team, tracing vulnerabilities through code, and scanning new commits <sup>[33](<https://openai.com/daybreak/defense-factory/>)</sup>.
- PostgreSQL shipped patch releases for all supported branches, fixing 52 security vulnerabilities and more than 140 bugs; PostgreSQL 14 is now end-of-life <sup>[34](<https://www.postgresql.org/about/news/postgresql-187-1712-1616-1520-1425-and-19-rc-2-released-3442>)</sup>.
- Codex Security is OpenAI's CLI and TypeScript SDK for finding vulnerabilities, checking whether they are real, and generating patches, with SARIF/JSON/CSV export and per-scan cost limits <sup>[35](<https://github.com/openai/codex-security/>)</sup>.
- CVE disclosures passed 100,222 in 2026, more than double 2025's total <sup>[36](<https://www.theregister.com/security/2026/11/13/this-years-bug-count-just-passed-100k/5309882>)</sup>.

## Cloud, networking and observability

- Fly.io redesigned its 6PN private network, replacing a synchronized routing table on every host with a lazy lookup that stores only 100 to 200 records per host, using VXLAN and standard kernel components instead of eBPF logic <sup>[37](<https://fly.io/blog/throwing-out-the-phonebook/>)</sup>.
- Uptime Kuma is a self-hosted monitor for HTTP(s), TCP, DNS and Docker, with over 90 notification services and multiple status pages <sup>[38](<https://github.com/louislam/uptime-kuma>)</sup>.
- Google Cloud made its Organization Policy MCP server generally available and added Gemini-powered natural language authoring of custom constraints <sup>[39](<https://cloud.google.com/blog/products/identity-security/ai-powered-cloud-governance-whats-new-in-organization-policy/>)</sup>.
- PyPI's redesigned project pages add a security tab showing where release files came from and warnings when provenance is missing, inconsistent or changed <sup>[40](<https://blog.pypi.org/posts/2026-11-06-ui-updates-complete/>)</sup>.
