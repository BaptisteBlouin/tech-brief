## AI models and LLM tooling

- Google DeepMind released Gemini 4 Neon, a fast frontier-level model for coding, knowledge work and science, scoring 61 on the Artificial Analysis Intelligence Index <sup>[1](<https://latent.space/p/ainews-gemini-4-neon-gdm-s-opus-sol-contender/>), [2](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/>)</sup>. It costs $3 per million input tokens and $15 per million output tokens, with cached input at $0.15 and a 1 million token context window <sup>[1](<https://latent.space/p/ainews-gemini-4-neon-gdm-s-opus-sol-contender/>)</sup>. Its predecessor Argon is retired, and the lineup now runs Carbon, Neon, Hydrogen from most to least expensive, with Carbon at half price until December 1st <sup>[1](<https://latent.space/p/ainews-gemini-4-neon-gdm-s-opus-sol-contender/>)</sup>.
- Neon's position is hard to read: an Agent Duel projection places it near Opus 5.5 but is a speed-based estimate with a wide uncertainty interval, not a measured leaderboard result <sup>[3](<https://micjm.com/blog/gemini-4-neon-looks-like-a-top-model/>)</sup>; in a private benchmark, Carbon took about seven times as many steps as GPT-6 Astra on bug fixes, half of them unnecessary <sup>[4](<https://kernel.dev/blog/why-is-gemini-4-carbon-taking-so-long/>)</sup>.
- Gemini 4 Genie 4, the interactive world model, opened to eligible Google AI Ultra subscribers in Project Genie, where users edit a world by typing prompts <sup>[5](<https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-now-available-project-genie/>)</sup>.
- A community reader notes that Gemini 4 pricing is harder to follow, since Hydrogen's discount and Carbon's expiring promotion change the ordering <sup>[6](<https://simonwillison.net/2026/Nov/18/llm-gemini/>)</sup>.
- Google Tunix and Gemma 4 show multi-turn, tool-using agentic reinforcement learning on a Cloud TPU v6e-8, training Gemma 4 E2B on the Plane Strike game <sup>[7](<https://developers.googleblog.com/multi-turn-agentic-reinforcement-learning-with-tunix-and-gemma-4-on-google-tpus/>)</sup>.
- Prime Intellect's Model Factory unifies RL, supervised fine-tuning, pre-training and inference in one control plane, with health checks and recovery from the latest checkpoint for long runs <sup>[8](<https://www.primeintellect.ai/blog/introducing-model-factory>)</sup>.
- Security researcher Paolo Galeone backdoored Qwen3-8B with a QLoRA adapter that fires only inside the pi agent harness; weight diffs catch it for open models but not for hosted APIs, so agents should be sandboxed and shell and network calls approved <sup>[9](<https://pgaleone.eu/ai/2026/11/14/backdooring-llms-and-trust/>)</sup>.
- Anthropic's compute spend grows about 4x per year, faster than OpenAI's 3x, reaching nearly $10 billion in Q3 2026 <sup>[10](<https://epoch.ai/data-insights/anthropic-openai-compute-spend-growth>)</sup>.

## Developer tooling and DevOps

- GitHub CLI v2.105.0 adds `gh event listen`, which waits for pull request events such as a submitted review, merge conflicts or completed check suites, replacing polling loops in scripts and agents <sup>[11](<https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli>)</sup>.
- Agents using `gh pr create`, `gh pr view`, `gh run watch` or `gh api` are now pointed to `gh event listen` instead of polling <sup>[11](<https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli>)</sup>.
- Enterprise Live Migrations from Azure DevOps to GitHub Enterprise Cloud with data residency is now generally available, syncing Git history, branches, tags and pull requests continuously until a brief cutover, with branch policies migrated as rulesets <sup>[12](<https://github.blog/changelog/2026-11-19-enterprise-live-migrations-from-azure-devops-generally-available>)</sup>.
- Red Hat Enterprise Linux 9 and 10 images for GitHub-hosted larger runners are now generally available <sup>[13](<https://github.blog/changelog/2026-11-19-red-hat-enterprise-linux-runner-images-now-generally-available>)</sup>.
- Cloudflare CLI 1.0 release candidate stabilizes its configuration and build formats and adds live JSON log streams, deployment previews and claimable temporary accounts <sup>[14](<https://developers.cloudflare.com/changelog/post/2026-11-17-release-candidate>)</sup>.

## Cloud, security and infrastructure

- GitHub Enterprise Cloud with data residency (GHE.com) now streams enterprise audit logs to Amazon S3 via OpenID Connect, so no long-lived AWS credentials need storing on GitHub <sup>[15](<https://github.blog/changelog/2026-11-19-s3-audit-log-streaming-with-openid-connect-expands-to-ghe-com>)</sup>.
- Versions 1.26.1 and 1.26.2 of Microsoft's agent-framework PyPI package were pushed from the official publisher account and contain a credential stealer that runs on every Python startup; treat any install as full credential compromise and rotate secrets and cloud identities <sup>[16](<https://opensourcemalware.com/blog/agent-framework-pypi-compromised>)</sup>.
- Java4Shell (CVE-2026-114938), a memory-corruption bug in the Java runtime, and two NGINX HTTP/2 flaws are patched in Docker Hardened Images, which rebuild as soon as upstream fixes land <sup>[17](<https://www.docker.com/blog/docker-patches-java4shell-and-the-nginx-http-2-with-docker-hardened-images/>)</sup>. Wiz reports the NGINX flaws can allow unauthenticated code execution <sup>[18](<https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities>)</sup>.
- A critical Puppet deserialization flaw (CVE-2026-115731, CVSS 9.4) is being exploited; CISA added it to its Known Exploited Vulnerabilities catalog, and Perforce patched affected versions on November 3 <sup>[19](<https://thehackernews.com/2026/11/hackers-exploiting-critical-puppet-rce.html>)</sup>.
- Gitea's public-only token scope bypass let restricted tokens act as full admins through the admin API, now tracked as CVE-2026-117635 <sup>[20](<https://escape.tech/blog/escape-research-found-a-scope-bypass-that-made-gitea-s-restricted-tokens-full-admins-it-s-now-cve-2026-117635/>)</sup>.
- AWS Security Hub now covers Google Cloud, monitoring GCP VMs, Artifact Registry images, Cloud Run functions and identities alongside AWS and Azure findings <sup>[21](<https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-gcp/>)</sup>.
- AWS released ExtendDB 1.0, an open-source Apache 2.0 DynamoDB-compatible adapter that runs on PostgreSQL, SQLite, Cassandra and MongoDB <sup>[22](<https://aws.amazon.com/about-aws/whats-new/2026/11/aws-extenddb-1-0/>)</sup>.
- Microsoft Fabric's Project Osmos builds, runs and validates Spark pipelines from a specification, but independent checks caught a daylight-saving bug the agent's own tests missed <sup>[23](<https://data-mozart.com/agentic-data-engineering-is-here-project-osmos-what-why-and-how/>)</sup>.

## Data, agents and engineering practice

- Pinecone exports cost and usage data in the FOCUS v1.4 format through the Cost and Usage Export API, available on the Enterprise plan <sup>[24](<https://www.pinecone.io/blog/cost-usage-export/>)</sup>.
- MongoDB acquired Firebolt and will run its analytics engine alongside the database, synced automatically <sup>[25](<https://www.mongodb.com/company/blog/news/mongodb-acquires-firebolt>)</sup>.
- PostgreSQL 19 adds read-your-writes consistency on standbys through the new WAIT FOR LSN command <sup>[26](<https://simonwillison.net/2026/Nov/19/postgresql-19/>)</sup>.
- Data contracts apply API design to datasets, so quality rules become assertions that tooling can pass or fail <sup>[27](<https://martinfowler.com/articles/data-contracts.html>)</sup>.
- Airbnb packaged the open-source Presidio as an in-process pipeline step, adding domain recognizers and multilingual evaluation to de-identify text before AI training <sup>[28](<https://medium.com/airbnb-engineering/de-identifying-text-at-scale-how-airbnb-protects-personal-data-in-ai-training-32f3ff8ff7d0>)</sup>.
- Weaviate found some agents were reading truncated documentation pages, which led them to wrong conclusions, and fixed the pages <sup>[29](<https://weaviate.io/blog/developer-experience-agentic-age>)</sup>.
- LinkedIn rebuilt its data lineage platform to capture dependencies from running jobs, covering about 6 million datasets <sup>[30](<https://www.linkedin.com/blog/engineering/infrastructure/rebuilding-data-lineage-at-linkedin-from-storage-to-compute>)</sup>.
