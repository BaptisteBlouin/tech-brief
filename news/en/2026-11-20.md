## Models and AI industry

- Anthropic closed its IPO at $83 per share, including the full exercise of the underwriters' option, for gross proceeds of about $93.5 billion <sup>[1](<https://www.anthropic.com/news/ipo-close>)</sup>. The stock debuted on Nasdaq at $111.50 and closed at $97.17 on its first day <sup>[2](<https://latent.space/p/ainews-anthropic-successfully-completes-largest-ipo-in-history-valued-at-1-5t/>), [3](<https://www.cnbc.com/2026/11/19/anthropic-ipo-ant-live-updates.html>)</sup>. Anthropic said it would pace training and deployment based on whether it could keep its systems safe and under human control <sup>[2](<https://latent.space/p/ainews-anthropic-successfully-completes-largest-ipo-in-history-valued-at-1-5t/>)</sup>. Its Class F shares carry 50.1% of voting power on most shareholder matters <sup>[2](<https://latent.space/p/ainews-anthropic-successfully-completes-largest-ipo-in-history-valued-at-1-5t/>)</sup>.
- OpenAI published a piece on combatting adversarial distillation, where an actor uses a frontier model's outputs without authorization to train a similar model without comparable safeguards <sup>[4](<https://openai.com/index/combatting-adversarial-distillation>)</sup>. It also introduced MedChemBench, a benchmark testing how well AI models read molecular structures, interpret experimental results and choose compounds to test next <sup>[5](<https://openai.com/index/introducing-medchembench>)</sup>.
- METR's updated time-horizon plot adds tasks that take humans much longer, and finds some capabilities still improving exponentially while models lag on judgment-heavy tasks compared with coding <sup>[6](<https://www.technologyreview.com/2026/11/20/1149399/the-most-misunderstood-graph-in-ai-just-got-a-major-update/>)</sup>.
- Stripe evaluated 14 coding agent setups on one-time payments, subscriptions and Connect integrations: agents met 78.1% of required criteria on average, but only 29.4% of runs met every required criterion, and all setups scored higher with Stripe's plugin <sup>[7](<https://stripe.dev/blog/stripe-integration-evals-methodology?amp%3Butm_medium=community>), [8](<https://stripe.dev/blog/stripe-integration-evals-methodology>)</sup>.
- Chrome's testing found coding agents passed 52% of its web development checks alone and 91% with Modern Web Guidance installed; common misses included restoring focus after dialogs close and reserving space for late-loading content <sup>[9](<https://developer.chrome.com/blog/top-10-things-ai-gets-wrong-in-web-dev>)</sup>.
- Replit's benchmark found 32 Opus agents reached an 18.9x NumPy workload speedup versus 3.7x for one agent within two hours, though gains depended on separable tasks and shared coordination boards <sup>[10](<https://frontier.replit.com/throwing-headcount-at-the-problem/>)</sup>.
- Together AI's Together Compiler uses AI agents to rewrite and fuse GPU kernels and beats its hand-written megakernels by about 28% on B200 (2,118 versus 1,649 tokens per second on Llama 3.2 1B) <sup>[11](<https://www.together.ai/blog/road-to-together-compiler>)</sup>.

## Security and infrastructure

- F5 and nginx.org disclosed ten nginx vulnerabilities on November 18, 2026 <sup>[12](<https://blog.cloudflare.com/nginx2root/>)</sup>. Five of them, named nginx2root by the Xint team, are memory corruption flaws that an unauthenticated attacker can use to crash an nginx worker or, per Xint's research, run commands on the server <sup>[12](<https://blog.cloudflare.com/nginx2root/>)</sup>. Xint also found a Linux kernel bug that can turn that foothold into root on the host, including from inside a Docker container <sup>[12](<https://blog.cloudflare.com/nginx2root/>)</sup>. Cloudflare states that origins reachable only through its proxy cannot be reached by attackers on the vulnerable code paths for the most serious flaws <sup>[12](<https://blog.cloudflare.com/nginx2root/>)</sup>.
- Ruby's ruby2shell (CVE-2026-132825), a critical heap buffer overflow in case-changing of strings, was disclosed November 19 with fixes in Ruby 3.3.14, 3.4.13 and 4.0.10; Rails and default Sinatra apps reach it before authentication <sup>[13](<https://blog.cloudflare.com/ruby2shell-waf-protection/>), [14](<https://verialabs.com/ruby2shell/>)</sup>. Cloudflare's WAF blocks it for all customers, including the Free plan <sup>[13](<https://blog.cloudflare.com/ruby2shell-waf-protection/>)</sup>.
- PHP fixed phpAfterShell (CVE-2026-126714, CVSS 4.0 9.2), a deserialization flaw in the default file-based session handler, in versions 8.2.36 to 8.6.0 <sup>[15](<https://blog.cloudflare.com/phpaftershell-waf-protection/>), [16](<https://thehackernews.com/2026/11/php-fixes-7-critical-flaws-including.html>)</sup>.
- A critical OpenJDK RCE (CVE-2026-114938, Java4Shell) in AVX-512 Base64 decoding affects OpenJDK 17.0.6 and later on x86-64, enabling pre-auth RCE in apps like Jenkins, Confluence and Tomcat; upgrade or disable Base64 intrinsics <sup>[17](<https://www.wiz.io/blog/cve-2026-114938-rce-java4shell-openjdk>)</sup>.
- Apache Roller versions 4.0.0 through 6.1.4 have an actively exploited unauthenticated deserialization flaw in the XML-RPC endpoint; upgrade to 6.1.6 or disable the servlet mapping <sup>[18](<https://thehackernews.com/2026/11/critical-apache-roller-rce-flaw-under.html>)</sup>.
- Rakuten Securities warns that data for about 4.47M accounts may have leaked <sup>[19](<https://www3.nhk.or.jp/nhkworld/news/20261117de77429/>)</sup>.

## Developer tools and DevOps

- GitHub's pull request Overview page, in public preview since November 5, 2026, no longer shows failed optional checks as blocking mergeable pull requests; force-push activity now links old and new commits <sup>[20](<https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview>)</sup>.
- Security advisory permissions are now generally available via custom repository roles, with four new permissions that avoid granting repository admin or the security manager role <sup>[21](<https://github.blog/changelog/2026-11-20-security-advisory-permissions-are-now-generally-available>)</sup>.
- GitLab 19.6 introduces Rapid Diffs, which renders merge request diffs on the server and streams them, cutting first file load to about 1.5 seconds <sup>[22](<https://docs.gitlab.com/releases/19/gitlab-19-6-released/>)</sup>.
- PostgreSQL 19 adds `REPACK (CONCURRENTLY)` for table optimization without downtime and the pg_plan_advice extension for plan stability <sup>[23](<https://www.postgresql.org/about/news/postgresql-19-released-3449/>)</sup>.
- Replit's DataCat is a self-hosted observability stack accepting OpenTelemetry and Datadog-compatible traffic <sup>[24](<https://github.com/replit/datacat>)</sup>. Firebase Crashlytics for Web is in public preview, grouping browser JavaScript errors <sup>[25](<https://firebase.blog/posts/2026/11/crashlytics-web-public-preview>)</sup>.
- OpenSRE is an open-source CLI agent that investigates failed CI/CD runs and pushes fixes for review, self-hosted with your own models <sup>[26](<https://github.com/Tracer-Cloud/opensre>)</sup>.
- Harness compares seven flaky-test tools and cites an IEEE study of 8.8 billion test executions where 9.8% to 16.3% of failed runs involved missed flaky failures <sup>[27](<https://www.harness.io/blog/flaky-test-tooling-landscape-2026>)</sup>.

## AI agents and tooling

- Claire Vo, who runs ChatPRD, describes a flood of token fraud from groups abusing the free trial and promo codes to resell tokens or run commercial work on top of its agent <sup>[28](<https://simonwillison.net/2026/Nov/20/token-fraud-is-here-and-its-bad/>)</sup>. A common prompt in the abuse was SVGs of pelicans riding bicycles, which the author suggests may identify the underlying model family <sup>[28](<https://simonwillison.net/2026/Nov/20/token-fraud-is-here-and-its-bad/>)</sup>.
- Linear's agents created 3% of its work a year ago and now create more than half; Linear has shipped an MCP server, a platform for building agents into Linear, and integrations with Codex, Cursor and GitHub Copilot <sup>[29](<https://latent.space/p/linear-scaling/>)</sup>.
- Google's Agent Anomaly Detection monitors ADK agents running on AWS, Azure or on-premises by analyzing OpenTelemetry traces and logs, without access to the agent runtime <sup>[30](<https://developers.googleblog.com/agent-anomaly-detection-safeguarding-agents-across-other-clouds/>)</sup>. Google's Mirror Dimension offers a controlled environment for testing browser-use agents without the live web <sup>[31](<https://blog.google/security/mirror-dimension-for-agents/>)</sup>.
- Apple is developing an autonomous agent for device control, apps, browsing and coding, and macOS 27.3 will warn users before granting third-party agents control of their Macs <sup>[32](<https://www.bloomberg.com/news/articles/2026-11-19/apple-is-working-on-ai-agent-for-device-control-apps-browsing-and-coding?amp%3Butm_source=tldrnewsletter>)</sup>.
- Replit's PINE is an open-source reactive agent harness for macOS and Linux that responds to file changes, webhooks and Telegram messages <sup>[33](<https://github.com/pmndre/pine>)</sup>. Vercel released Board, an experimental message board where agents claim tasks and share context <sup>[34](<https://vercel.com/blog/introducing-vercel-board>)</sup>.
- Perplexity Computer can now build and update its own skills from each user's past sessions <sup>[35](<https://www.perplexity.ai/hub/blog/self-improving-skills>)</sup>.
- Hosted agent APIs make harnesses easier to swap, but with the same instructions and tools, Gemini queried a code graph while Claude mostly searched from the shell, so teams should retest after a model swap <sup>[36](<https://davenporter.com/writings/agent-harnesses-cheap-to-swap-behavior-isnt>)</sup>.
- Hugging Face introduced harness adapters to tune a model for a given harness, improving performance and cost <sup>[37](<https://huggingface.co/blog/harness-adapters-at-scale>)</sup>.

## Research and evaluation

- Spotify explores when offline AI evaluations can support a launch decision without an A/B test; borderline changes go to A/B tests and some other decisions are randomly audited for drift <sup>[38](<https://engineering.atspotify.com/2026/11/when-can-you-ship-on-offline-evals-alone>)</sup>.
- Epoch's Capabilities Index aims to summarize AI progress in a single continuously updatable number <sup>[39](<https://asteriskmag.substack.com/p/the-most-important-number-in-ai>)</sup>.
- Sandboxed models on a shared inference server could still signal each other in contrived tests, since one model's request slightly shifts the other's calculations <sup>[40](<https://www.lesswrong.com/posts/7wzWuLP3HhyBLmKfo/models-can-communicate-via-inference-servers-despite-being>)</sup>.
