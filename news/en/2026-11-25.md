## AI models and LLM tooling

- Google DeepMind is back in the frontier race, with the Gemini 4 Neon model now the talk of the town and its adoption showing an unusually strong breakout trend <sup>[1](<https://latent.space/p/ainews-gemini-4-neon-marks-gdm-s-full-return-as-a-frontier-lab/>)</sup>. Gemini 4 Argon, Carbon and Hydrogen were also covered in that roundup <sup>[1](<https://latent.space/p/ainews-gemini-4-neon-marks-gdm-s-full-return-as-a-frontier-lab/>)</sup>.
- Simon Willison traces three LLM inflection points over the last twelve months, anchored on the release of Claude Opus 4.5 a year ago, which Anthropic said handles ambiguity and multi-system bugs without hand-holding <sup>[2](<https://simonwillison.net/2026/Nov/24/llm-inflection-points/>)</sup>.
- Cognition released SWE-2.1, a coding and agent model trained with reinforcement learning on top of Kimi K3, which roughly doubles SWE-2's score on Terminal-Bench 4.1 to 50.0 and adds stronger security skills <sup>[3](<https://cognition.com/blog/swe-2-1>)</sup>.
- Inkling 2 Mini is a looped Mixture-of-Experts model with about 26B total parameters (3B active), multimodal inputs and a 1M-token context window; a Hugging Face post tunes its inference on a single RTX PRO 6000, and its published vLLM and SGLang recipes target B200 and GB300 rather than sm120 cards <sup>[4](<https://huggingface.co/blog/inkling-2-mini-inference-hillclimb>)</sup>.
- Ternary Bonsai 2.5 27B has markedly stronger agentic coding and multi-turn tool use than its predecessor while keeping a 5.9 GB footprint <sup>[5](<https://prismml.com/news/bonsai-2-5-27b>)</sup>.
- Google's Antigravity now shows live task checklists for long jobs and lets users pick separate planner and executor models <sup>[6](<https://www.testingcatalog.com/google-adds-task-checklists-to-antigravity-and-carbon-for-pro/>)</sup>.
- Math is moving fast: an OpenAI preprint claims the matrix multiplication exponent is exactly 9/4, and a separate paper reports matching bounds for the finite Fourier transform <sup>[7](<https://latent.space/p/ainews-math-proofs-are-landing-faster-than-we-can-read-them/>), [8](<https://github.com/openai/math/blob/main/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/paper.pdf>)</sup>. A Riemann Hypothesis claim built with AI help has passed two independent verifications so far, though it still faces scrutiny <sup>[9](<https://www.wsj.com/tech/ai/riemann-hypothesis-anthropic-math-levent-alpoge-75351bcb?amp%3Breflink=desktopwebshare_permalink&amp%3Butm_source=tldrnewsletter>)</sup>.

## Agents, tooling and security

- Cloudflare's Search for Agents is a dashboard toggle that creates an AI Search instance, indexes a zone's content and makes search available to agents on the domain <sup>[10](<https://blog.cloudflare.com/search-for-agents/>)</sup>.
- AWS WAF can now discover LLM, MCP and A2A endpoints behind API Gateway, ALB and CloudFront, and protect them with a managed rule group using Bedrock Guardrails, though content inspection costs extra <sup>[11](<https://aws.amazon.com/about-aws/whats-new/2026/11/waf-ai-endpoint-discovery-protection/>)</sup>.
- Docker shows how to enforce agent guardrails with sandboxed Claude Code and MCP servers, blocking unapproved outbound requests at the network boundary <sup>[12](<https://www.docker.com/blog/prove-your-ai-agent-guardrails-work/>)</sup>.
- Amazon reports that AI agents running on the open-source Cairn pentest framework found and exploited a zero-day with little human input, and Palo Alto Networks tracked a Cairn campaign that breached at least 10 organizations <sup>[13](<https://arstechnica.com/security/2026/11/amazon-says-hackers-ai-agents-found-and-exploited-0-day-with-little-human-input/>)</sup>.
- Research on swarms finds that, at equal token budgets, multi-agent configurations run faster but less efficiently than single agents, which outperform them once context is refreshed <sup>[14](<https://www.paradigm3.org/research/swarms>)</sup>.
- A harness analysis argues that the harness around a model (context, tools, permissions) determines what an agent can do safely <sup>[15](<https://www.infoq.com/news/2026/11/harness-new-operating-system/>)</sup>.
- A reverse-engineering teardown of always-on assistants compares tool use, memory and scheduled or event-driven work <sup>[16](<https://x.com/sarahfim/status/2125402373149557079>)</sup>.
- Fly.io reports that agents now make at least 55% of its deployments and supports auth.md signup plus a Machine Payments Protocol for agent top-ups <sup>[17](<https://fly.io/blog/holding-the-door-for-agents/>)</sup>.
- WebMCP is a draft browser API that lets sites expose actions as tools agents can call, with a worked restaurant-booking example <sup>[18](<https://polypane.app/blog/getting-started-with-webmcp-building-and-testing-tools>)</sup>.

## DevOps, infrastructure and engineering practice

- Application-level sharding creates operational burdens such as hard resharding and cross-shard queries, as Intercom, Etsy and Slack found <sup>[19](<https://planetscale.com/blog/why-you-shouldnt-do-app-level-sharding>)</sup>.
- Frank Rousseau shares a process for agentic coding on an open-source project covering prompting, context, reviews and large QA or migration work <sup>[20](<https://blog.frankrousseau.fr/agentic-coding-on-an-open-source-project/>)</sup>.
- Antithesis details the disk faults a fault injector must emulate (power loss, torn writes, I/O errors, latency) to surface bugs <sup>[21](<https://antithesis.com/blog/2026/nightmare-mode/>)</sup>.
- Sofka is a Rust Kubernetes terminal UI with built-in Flux CD and Argo CD actions and read-only guardrails <sup>[22](<https://github.com/nklmilojevic/sofka>)</sup>.
- Harness argues that AI coding tools raise pull-request volume enough to overload Jenkins build queues <sup>[23](<https://www.harness.io/blog/is-your-jenkins-pipeline-ready-for-what-cursor-just-handed-you>)</sup>.

## Security incidents and supply chain

- A critical deserialization flaw in the abandoned Idunno.AntiCsrf ASP.NET library (CVE-2026-131914, CVSS 9.3) is being exploited for unauthenticated RCE with no patch, so defenders should replace it with the built-in anti-forgery APIs <sup>[24](<https://thehackernews.com/2026/11/hackers-exploit-critical-aspnet-anti.html>)</sup>.
- A Databricks review of about 5,400 malicious npm packages finds compromised legitimate packages account for over 99% of downloads, and attackers are shifting to CI pipelines and OIDC trusted publishing <sup>[25](<https://www.databricks.com/blog/what-5400-malicious-npm-packages-reveal-about-software-supply-chain-risk-2026>)</sup>.
- Elecbrakes trailer brake controllers accepted unauthenticated Bluetooth commands that could activate the brakes; EB2 and VM1 were fixed while ELBC 2000 remains unpatched <sup>[26](<https://elementdigital.com.au/blog/brake-check-trailer-brakes-over-bluetooth/>)</sup>.
- Turnitin disclosed unauthorized activity on customer-facing systems, with no details yet on the entry point or data taken <sup>[27](<https://www.bleepingcomputer.com/news/security/turnitin-discloses-cyberattack-affecting-customer-facing-systems/>)</sup>.

## Society and public data

- AI-driven requests are straining small-town public records systems in the US: a Vermont town clerk reports public records requests on purchasing data rising from yearly to monthly, often from companies doing targeted research <sup>[28](<https://www.technologyreview.com/2026/11/25/1149702/ai-is-straining-americas-open-records-systems/>)</sup>.
